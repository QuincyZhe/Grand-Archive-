# 游戏术语

#### **Activate/Activating 启动/进行启动**

1. 启动牌是指将该牌从其当前所在的区域（通常是手牌）中取出，支付其代价，并将其置入效果堆叠以进行结算。玩家若具有时机，且合规允许启动该牌，则可以启动牌。
2. 启动能力是指指明被启动的能力，支付代价，并将该能力置入效果堆叠以进行结算。玩家若具有时机，且合规允许启动某能力，则可以启动该能力。

#### **Awake 备战**

1. 战场上的牌若处于直立状态，则认定为备战。
2. 该牌的能力若要求待命（例如攻击，或作为启动代价），则只有在该牌备战时才能启动。
3. 牌进入战场时处于备战状态。

#### **Banish 除外**

1. 除外牌是指将该牌从其当前所在的区域中取出，并将其置入其拥有者的除外区。
2. 被除外的牌是指已被置入除外区的牌。
3. 被除外的物件以此方式离场时，不认定已被消灭或已死亡。

#### **Buff Counters 增益指示物**

1. 物件上的每个增益指示物使该物件的力量和生命数值各增加+1。
2. 由增益指示物造成的数值修改为固定。

#### **Control and Ownership 操控权与拥有权**

1. 物件或牌的启动的操控权默认赋予启动对应牌的玩家。
2. 操控指定物件的玩家称为该物件的操控者。
3. 若牌、物件、效果或能力的操控权未被指定，则操控权默认归属于其拥有者。例如，若某个伙伴被压制，新的伙伴物件将处于该伙伴牌的拥有者的操控之下。
4. 若某张牌或某个物件的触发能力被放置到效果堆叠上，则在该能力被放置到效果堆叠上时，该能力的操控权被赋予该牌或物件的操控者；该物件操控权的变更不会追溯地变更操控该能力的玩家。
5. 牌的拥有者不一定始终操控该牌。
6. 牌的拥有权（在 Grand Archive 的一场游戏内）指认给游戏起始时在其主牌库、素材库或备牌中持有该牌的玩家。
7. 拥有指定牌的玩家称为该牌的拥有者。
8.  操控权的变更不会变更牌的拥有权。



#### **Copy 复制**

1. 复制既可以指复制物件或牌的启动的效果，也可以指被复制的物件或牌。
2. 当物件被复制时，复制物件成为该牌印刷牌面的克隆，无视任何修正，例如额外的指示物或状态条件（备战/待命状态、不会唤醒等）。
3. 当牌的启动被复制时，复制启动成为效果堆叠中该牌的复制，其所有模式、启动选择，以及其他被修改的启动性质均与原始相同。
4. 若效果被复制，则其实质上被第二次置入效果堆叠，并从原始复制所有相关的模式、启动选择及参数。

#### **Damage Counters 伤害指示物**

1. 伤害指示物标记于英雄之上，用于追踪英雄的生命。
2. 指示物可从 0 开始递增；当伤害指示物达到或超过该英雄的生命数值时，该英雄认定被击败。
3. 伤害指示物可被恢复的效果移除。

#### **Destruction 消灭**

1. 消灭是可以影响战场上任何物件的效果。
2. 消灭物件是指将该物件从战场移动到其拥有者的墓场。若该牌为衍生，则会将其从游戏中移除。
   1. 被消灭的单位在去往墓场时认定为已死亡。若作为去往墓场的代替，其将被除外、置入牌库顶部/底部，或置入手牌，则不被认定为已死亡。
3. 物件被消灭，当且仅当：其因具体指示消灭该物件的效果而被消灭、因基于状态的效果而被消灭，或被牺牲。牌因任何其他原因而进入墓场或被放置到墓场中，并不意味着其已被消灭。
4. 非礼装武器若其耐久指示物的数目为 0——无论通过战斗还是其他手段——则认定为因基于状态的效果而被消灭。
5. 当单位的生命为 0 或小于 0，或其所受伤害标记（临时的或凭借伤害指示物的）等于或大于其生命时，该单位因基于状态的效果而被消灭。
6. 当可攻占领地上的耐久指示物数目达到 0 时，该领地因基于状态的效果而被消灭。
7. 指定某物件被消灭的效果或牌，仅当该牌于效果结算时立即进入墓场时，才会使该物件死亡。

{% hint style="warning" %}
由消灭效果导致的进入除外区的处理，不允许依赖于该物件死亡或被送入墓场的效果生效，因为游戏期间不存在任何该牌能认定已进入墓场的时刻。
{% endhint %}

#### Died/Dies and Kills/Killed **已死亡/死亡与击杀/被击杀**

1. 死亡是用于指示战场上单位将进入墓场的术语。战场上的单位在其被效果直接消灭或被基于状态的效果消灭（例如生命为 0 或小于 0）时死亡。
   1. 被牺牲的单位认定为已死亡并已被消灭。
   2. 非单位不会死亡，但仍认定为已被消灭。

{% hint style="warning" %}
例如，消灭或消灭效果击杀伙伴，则该伙伴认定为已死亡。可攻占领地因耐久指示物降至0而被消灭，并不会死亡。这意味着击杀时等效果对非单位不会触发。
{% endhint %}

2. 当且仅当单位直接从场上进入墓场时，该单位才认定为已死亡或被击杀。

{% hint style="danger" %}
若作为被送入墓场的代替，其将被除外，则该牌按定义不被认定为已死亡。
{% endhint %}

#### Discard **弃置**

1. 当玩家弃置牌时，其必须将该牌从指定区域移动到其墓场。若未指定区域，则牌默认从手牌中弃置。
2. 弃置牌可被要求作为打出牌或启动能力的额外或备选代价。如同支付代价的正常步骤，弃置必须在该牌或该能力被完全打出或启动之前完成。
3. 通常，使玩家弃置或要求弃置作为代价的效果，允许其选择哪张牌或哪些牌被弃置。某些效果可能要求弃置随机地进行。

#### Distant 远离

1. 远离是单位的特性。
2. 单位成为远离之后，其保持远离直到其操控者回合结束。
3. 远离特性与其他回合结束时效果同一时刻结束。

#### Durability Counters **耐久指示物**

1. 武器具有耐久指示物，其代表武器可被用于攻击的次数。
2. 耐久指示物可被添加以超过武器的耐久数值。
3. 武器在耐久达到 0 时被消灭。

#### Element **属性**

1. 牌的属性由其牌面右上方的名称和符号代表。
2. 属性对玩家打出牌施加制限，除非该属性在其英雄之一的属性标识之内。
3. 属性归于三个类：无、基础和进阶。
   1. 无是没有任何制限的默认属性；玩家始终得以打出此属性的牌。
   2. 基础属性为水、火和风，通常由游戏开始时置入场上的等级 0 英雄解锁。其他效果也可以启用这些属性。
   3. 进阶属性是任何不归于无或基础属性类的属性。这些属性通常在英雄于其传承中达到等级 3 之后，或在特殊情境下解锁。
      1. 崇高是特殊的进阶属性；只要玩家操控为其启用另一进阶属性的英雄，崇高即对该玩家默认启用。

#### Enlighten Counters **启迪指示物**

1. 启迪指示物授予被放置于其上的物件下述能力："从\[牌名]上移除3个启迪指示物：抽一张牌。"
2. 放置于英雄身上的启迪指示物在玩家英雄升级时存留。

#### Ephemeral **虚化状态**

1. 虚化状态是可以修改效果堆叠中牌的启动、战场上的物件或意图的特性。
   1. 虚化状态物件若将离场，则将被除外。
   2. 虚化状态牌的启动在其结算或离开效果堆叠时将被除外。
      1. 若虚化状态牌的启动被无效或失效，则作为去往墓场的代替，其将被除外。
   3. 虚化状态意图在战斗结束期间被除外。
      1. 任何命中时能力将根据该意图的最后已知信息，参照除外区中该能力的来源。

#### Fast **快速**

1. 快速是行动牌的性质，决定该牌何时可以被启动。参见时点以获取进一步详情。
2. 玩家行动或带有快速修正的牌，在该玩家具有动作时机期间，或若该玩家为回合玩家则在该玩家的主要阶段期间，可以被启动。

#### Fizzle **失效**

1. 失效可以指代牌或能力因游戏状态——目标或游戏条件造成启动不合规，该牌或效果将不结算——而未能结算。
   1. 对英雄具现而言，若具现该牌起初有效的传承或等级要求在其待结算过程时成为不合规（例如通过对该英雄牌进行降级），则英雄牌可以失效。
2. 已失效的牌或能力不被认定为已被无效。

#### Fostered **培育状态**

1. 培育状态是伙伴的特性。
2. 单位默认为未培育状态。
3. 伙伴可被其他牌，或被培育关键词能力所生成的基于状态的检查，使其为培育状态。
4. 伙伴只能进入一次培育状态。

#### Gather **采集**

1. 采集定义进行采集的玩家行动。
2. 为了采集，玩家从六个不同的衍生道具之中随机选取一种原料并将其召唤。六种原料为 Blightroot、Fraysia、Manaroot、Razorvine、Silvershine 和 Springleaf。每种原料都具有两个与酿造能力配合使用的特征子类别：助剂或催化剂，以及根、叶或花。
3. 若玩家使用采集衍生板，其可以使用骰子或其他计数用的衍生来指示每种原料的数量。每个仍认定为战场上的独立物件，且可以被正常地进行交互。

#### Generate **生成**

1. 生成定义生成牌的玩家行动，或在 Grand Archive 的一场游戏余下时间内永久地从游戏外添加牌。被生成的牌在游戏终结后不存留；任何被生成的牌在游戏已结束后将从游戏区及对应区域中被移除。
2. 生成牌默认将指定的被生成牌添加到该效果的操控者手牌中。若为该生成效果指定了区域，则该牌将在游戏持续时间内添加于该指定区域中。若该区域不再被提供，其将回退到默认情形，即被添加到手牌。
3. 被生成的牌可以超过由组建牌组限制施加的数量上限。
4. 玩家必须拥有其希望在游戏中生成的每张牌的实体副本。
5. 若玩家尝试生成牌但没有代表被生成牌的实体牌，则该牌的生成失败；该玩家未能生成该牌。
6. 若未指定区域，或当玩家被指示将被生成牌置入那里时、该牌被放置到其中的区域不存在，则该牌默认被添加到手牌。

#### Glimpse **预视**

1. 预视定义进行预视的玩家行动，通常表述为"预视 N"。
2. 为了预视 N，玩家查看其牌库顶部的 N 张牌，并将其中任意数目的牌以任意顺序放置到其牌库顶部，将其余的以任意顺序放置于其牌库底部。

#### Have, Gain, Get, Become/Are **具有、获取、获得、成为/是**

1. "Have" and "Gain" “具有”和“获取”："具有"和"获取"在效果将能力或效果赋予一组所述牌或物件时被使用。此效果对该系列中匹配所述标准的所有牌或物件而言是固定【链接】。这将延伸至该效果起初起始之后可被添加到所述一系列牌中的任何牌或物件。若牌或物件之前未"具有"所赋予的能力或效果，则认定为其已获取该能力或效果。"具有"不指定该特征被赋予的具体时刻，而"获取"在具体时间点授予能力。
2. "Get" “获得”："获得"在效果将数值修改赋予一组所述牌或物件时被使用。此效果固定地应用于该组中匹配所述标准的所有牌或物件，且只要持续效果存留，此效果即保持有效。对一次性效果而言，此效果仅认定该效果将要结算时存在的该组。另外，使用"只要\[条件]"等措辞的有条件地固定效果，仅在该条件被达成时应用此效果。
3. "Become" and "Are" “成为”和“是”："成为"和"是"在效果将特征（例如定类）或特性的变更指定给一组牌或物件时被使用。所述一组中所有牌或物件均固定地"成为"或"是"某特性。"成为"用于在具体时刻将特性设定为某状态，而"是"将所述牌/物件的默认特性设定为该模式，但无具体起点。
   1. 特性的状态仅当牌或物件的特性的状态之前和之后不同时，才认定为已被变更。若某状态下的牌或物件成为相同状态或"是"相同状态，则其不被认定为状态的变更。

#### **Hit 命中**

1. 命中一般在与命中时触发能力相关时认定。
2. 单位被造成战斗伤害时，即被命中。
3. 若未造成伤害或所造成的伤害为零，则单位不被认定为命中。
4. 非战斗伤害的来源不会使该单位认定为命中。

{% hint style="warning" %}
战斗伤害是由单位在战斗期间基于攻击和反击行动直接造成的任何伤害；进行反击或进行攻击的单位将造成战斗伤害，并认定为已命中其攻击/反击目标。&#x20;
{% endhint %}

#### Influence **影响力**

1. 玩家的影响力等于其手牌及回忆区中牌的总数目。

#### Inner Lineage **内部传承**

1. 英雄的内部传承是该英雄传承中除最顶端牌（即该英雄自身）以外的所有牌。
2. 内部传承可以包含任何牌；牌必须位于内部传承中才能使用传承解放能力。

#### Label Keywords **标签关键词**

1. 标签关键词以后跟长破折号的加粗斜体文本的形式存在于牌上，它们不充当正常的关键词，而是它们将指代一大类相似的机制，各个牌在该关键词的措辞或条件上或有差异。
2. 标签关键词可被能力或效果参照，且确实算作牌的特征。
3. 标签关键词列表：

* 均衡 Blance        ：此关键词代表牌将基于玩家是否在其手牌和回忆中具有相等的量的牌而给予额外效果。
* 牌艺 Cardistry    ：此关键词体现参照由玩家操控的代价不同的同花伙伴数目的能力。通常，这些能力对由玩家操控的每个具有不同封存代价的同花伙伴，都具有 1 封存的启动代价减免。
* 洪泛 N Deluge N：此关键词代表关于墓场中具有 N 张或更多水牌的条件的固定能力。
* 和鸣 Harmonize ：此关键词代表牌将基于旋律子职业牌是否于此回合期间、于该牌结算过程期间先前被启动而给予额外效果。
* 维持 Upkeep      ：此关键词提供每回合必须被达成的代价或条件，通常带有未达成该维持条件的负面效果。
* 骑术 Equestrian ：此关键词体现与操控马伙伴配合使用而起作用的能力。该马伙伴可以具有任何定类，只要"马"作为子类别存在且"伙伴"作为类别存在。

#### Last-Known Information **最后已知信息**

1. 最后已知信息【链接】是诸如物件或牌的状态、特征或数值等，在该牌变更区域时被追踪的信息。
2. 某些效果依赖于牌或物件在具体区域时的信息，且将使用该信息，犹如该牌仍位于该区域中，以决定效果。
3. 最后已知信息仅认定发生的最后一次区域变更，而不认定从此前的区域变更中被延续的任何信息。

#### Leave/Leaves 离开

1. 这些是用于指示战场上非英雄物件将离场并移动到另一区域时的可互换术语。

#### Level (base) **等级（基本）**

1. 英雄的基本等级是印刷于英雄牌左上方的等级。此等级决定英雄的升级序列，且不包括任何等级数值修正，例如"你的英雄获得+X等级"。基本等级是英雄牌的一项固定特征。基本等级通常仅认定用于使英雄升级，而非符合能力和效果的等级制限。

#### Level Counters **等级指示物**

1. 等级指示物代表英雄上每个等级指示物为 +1 LV。
2. 这些指示物不修改英雄的基本等级。

#### Level Up **升级**

1. 升级或进行升级的动作，是指玩家将下一等级英雄添加到该英雄的传承之一上。此不使用效果堆叠。升级将使被放置到传承上的牌的任何"参战时"能力触发。
2. 升级自身不视为具现，但可以是具现英雄牌的结果。
3. 升级不基于游戏中其他效果的任何等级修改，而仅基于英雄牌的印刷（基本）等级。

#### Lineage (term) **传承（术语）**

1. 传承是全组专用于代表英雄的牌。传承包括内部传承【链接】以及最顶端牌（即代表的英雄）在内的所有牌。
2. 传承的名称沿用最顶端牌的名称（不包括头衔或别号），任何升级制限或英雄制限能力将把该名称作为依据。

#### Load **装填**

1. "装填"是玩家行动，意为将牌从其当前所在的区域取出并将其移动到另一张牌之下。顶部的牌认定为以该牌"已装填"，而被置于下方的牌成为该牌之下的"已装填牌"的一部分。

#### Loaded **已装填**

1. 已装填是物件的特性。
2. 牌默认为未装填。
3. 当物件在其已装填牌【链接】区域中具有牌时，牌认定为已装填。

#### **LV**

1. "LV" 指代你的英雄的等级，为你的英雄牌上标示的等级加上游戏中等级修改效果的总和。
2. LV 通常用于需要计算或参照变量的效果或规则文本。
3. LV 可以取负值。若被用于计算代价减免（例如效率），则负的 LV 值将增加代价。当被用于对牌、指示物或物件计数或选取时，负的 LV 认定为0（你不能选取负数量的牌或物件）。

#### Modes **模式**

1. 模式是被列出于牌上的效果，要求玩家就若牌或效果将要结算时哪项效果将被执行作出选择。这些选择在牌被放置到效果堆叠上待结算之前作出。具有这些模式的牌和能力可以叫作模态。

#### Negate **无效**

1. 某些效果可能指定"无效"特定牌、游戏行动或效果。"无效"是玩家行动，意为将牌从效果堆叠移除并将其置入墓场。被移除的牌认定为"被无效"。其不结算；其不生效。任何本会作为被无效的牌/行动/效果的结算过程结果而发生的效果均不发生。
   1. 某物被无效时，已支付的代价不被退还。

#### Negated **被无效**

1. 若牌被无效，则被无效的牌被送入的默认区域是墓场。然而，若该牌具有规则文本以修改其在结算过程期间本会去往的地方，或其去处区域由于替代效果或其他能力而被变更，则该去处区域在其被无效期间被延续，其将不去往墓场。此亦同样适用于由超类别（例如礼装）所设定的规则。
   1. 任何依赖于被无效牌的启动的触发仍然发生。

{% hint style="info" %}
![](<../.gitbook/assets/image (29).png>)

一个已支付额外2的被无效的 Crux Sight，在其被无效时将被除外。此外，被无效的礼装物件将因礼装超类别修改其本会被放置之处而被除外。&#x20;
{% endhint %}

#### Obedience **服从**

1. 对于不听从玩家的伙伴，该玩家不能用其攻击或启动其能力。玩家仍可以使该伙伴反击。
2. 伙伴默认听从操控其的玩家。
3. 伙伴的固定能力和触发能力始终发生，无论服从情况，但这些能力的拥有权取决于该伙伴的操控权。某些能力可能需要来源物件的服从才能正确地结算。
4. 进行攻击的伙伴，即使在其不再听从原本宣告攻击的玩家后，仍将继续进行该攻击。此包括在傲慢条件突然不被达成、或物件操控权在攻击期间变更的情况。

#### Opportunity **时机**

1. 时机被定义为玩家具有机会进行动作的时间，以回应其自身或另一玩家所进行的玩家行动，回应待结算的效果或玩家行动，或回应阶段变更。
2. 当时机产生时，其首先被赋予回合玩家，并以回合顺序依次传递给其他玩家。
3. 主要阶段之外的阶段结束的根据为没有玩家具有时机、且没有事件待结算。

#### Play/Played **打出/被打出**

1. 牌在其被具现或被启动后认定为已被打出。
2. 具现或启动牌算作打出该牌。

#### Player Action **玩家行动**

1. 玩家行动是玩家可以进行的游戏中独特的行动。例如，启动或具现牌、攻击、启动能力等。
2. 玩家行动顺序是玩家在其将接收时机时可以进行行动的顺序。在玩家行动被进行或时机被赋予后，其首先被赋予回合玩家。回合玩家可以首先进行动作，之后非回合玩家可以各自轮流进行游戏所允许的玩家行动。此可以叫作回合玩家 / 非回合玩家顺序。

#### Players **玩家**

1. 玩家是参与 Grand Archive 游戏的个体。"回合玩家"是操控当前回合及其进程的玩家，"非回合玩家"是任何非回合玩家的玩家。

#### Preparation Counters **准备指示物**

1. 准备指示物是可以被放置于英雄上的一种指示物。
2. 启动具有伺机关键词的牌时，准备指示物可以作为额外代价被支付。

#### Recover **恢复**

1. 恢复定义进行恢复伤害的玩家行动，通常表述为"恢复 N"。
2. 为了恢复 N，玩家从其英雄上移除 N 个伤害指示物。
   1. 若玩家尝试恢复多于其英雄上伤害指示物的数目，则其作为代替从该英雄上移除所有伤害指示物。
      1. 玩家被指示恢复非零的量，而其英雄上没有伤害指示物时，仍将触发条件为"每当你恢复时"的能力。
   2. 玩家不能移除多于英雄上现有伤害指示物的数目，例如，若英雄具有两个伤害指示物而玩家恢复 3，则仅移除 2 个伤害指示物。

{% hint style="info" %}
例如，对于文本为"作为启动此牌的额外代价，恢复 10"的牌，启动该牌的玩家的英雄必须具有至少10个伤害指示物、且这些指示物必须能被移除。&#x20;
{% endhint %}

#### Redirect **重定向**

1. 重定向意为将牌或能力的目标变更为另一有效目标。
2. 若效果指定选取而非定为目标，则其不能被重定向。

#### Reflexive Trigger **反射触发**

1. 反射触发是位于效果或能力之内的触发，仅在该触发的条件被达成、且该能力或效果的起初的部分完全结算后，被放置到效果堆叠上。
2. 反射触发的来源认定为生成该反射式触发的效果或能力的原始来源。

{% hint style="info" %}
![](<../.gitbook/assets/image (30).png>)

例如，Umbra Sight 允许玩家可选地将一张牌抽到其回忆中，并将 Umbra Sight 置于该玩家英雄传承的底部。"当你这样做时，…"之后的剩余文本是反射触发；其是一个触发能力。当 Umbra Sight 结算、第二张牌被可选地抽取、且 Umbra Sight 被置于该英雄传承底部之后，此触发能力被放置到效果堆叠上。
{% endhint %}

#### Reserve **封存**

1. 封存指代玩家将牌从其手牌中取出并放置到其回忆区中的玩家行动。
2. 被封存的牌在追忆阶段期间移回玩家手牌。

#### Rest/Rested **待命/待命状态**

1. 使战场上的物件待命，是指将该物件从直立（备战）方向转为水平（待命状态）方向。
2. 待命符号：待命符号将作为向右旋转 180 度的带黑色边框的箭头出现于牌上。
3. 待命符号通常指明待命作为启动能力的代价。
4. 战场上的物件若处于水平方向，则认定为待命状态。
5. 已经处于待命状态的物件不能待命；玩家不能使处于待命状态的物件待命。若效果尝试使处于待命状态的物件待命，无事将生效。

#### Retaliate/Retaliation **反击/反击**

1. 为了反击，进行防御的玩家可以在战斗阶段的反击步骤期间使进行防御的单位待命，以代表其在战斗期间进行反击。
2. 待命是反击的代价；已经处于待命状态的单位不能反击。
3. 进行反击的单位将在伤害步骤期间根据其力量对进行攻击的单位造成伤害。
4. 当反击被宣告时，进行反击的单位使进行攻击的单位成为反击目标，即使进行攻击的单位在战斗阶段期间停止进行攻击，此亦被维持。
5. 没有力量数值或力量为 0  的单位不能反击。
6. 反击是将进行防御的单位待命以对进行攻击它的单位根据其力量造成伤害的动作。
7. 单位仅当其"反击前"（参见战斗的反击步骤【链接】）是战场上的物件时，才能反击。
8. 在战斗阶段期间被宣告为进行反击之后获取潜行的单位，仍将在伤害步骤期间对其攻击者进行反击并相应地造成伤害。

#### Reveal **展示**

1. 能力、效果或游戏规则可以告知玩家展示游戏区域中的一张牌或一系列牌。
2. 为了展示牌，玩家将该区域中指定的牌取出，并将其以面朝上作为公开信息提供给游戏中的所有玩家。
3. 牌保持被展示，直到下个离散游戏状态、直到玩家进行玩家行动，或直到下一次基于状态的效果被检查。
4. 被展示的牌可以以玩家所希望的任何方式被记下或被记录，但不可请求被展示的牌保持被展示；被展示牌的信息状态（私有对公开）在该牌停止被展示后还原为其在被展示之前的原始状态。
5. 从私有区域展示的牌应当在这些牌停止被展示后在该区域的其他牌之中被洗切或被随机化。
6. 已经为公开信息或已经被认知的牌可以被展示任意数目的次数。

#### Sacrifice **牺牲**

1. 牺牲物件是玩家行动。
2. 牺牲意为将物件从战场或于游戏中移除，并将其置入墓场；或者，若该物件为礼装或英雄，则置入除外区。
   1. 被牺牲的物件的类别将由该效果或代价确定。
   2. 若物件作为效果、能力或启动的支付代价而被牺牲，则该物件在所有其他代价被支付的同时被牺牲。
   3. 玩家只能牺牲其所操控的物件。
   4. 即使替代效果将使该物件去往除墓场以外的区域，该物件仍认定为已被牺牲。
3. 若物件具有死亡时触发，或由于该物件为了启动牌或能力而被牺牲将触发能力，则该能力将被放置到效果堆叠上的该牌或能力之上并首先被结算。
4. 若物件具有死亡时触发，或由于该物件作为效果的结果而被牺牲将触发能力，则该能力将在指定该牺牲的原始能力的所有效果都已结算后被放置到效果堆叠上。

#### Scavenge N 搜寻 N

1. 搜寻 N 是指示词，意为从牌库顶部展示牌，直到展示出具有所述特征的牌或直到已展示 N 张牌。被找到的匹配该搜寻标准的牌称为被搜寻出的牌。在玩家展示被搜寻出的牌后，将其置入手牌。其余的被展示的牌将以随机顺序置入牌库底部。若在 N 张牌被展示之后未搜寻到牌，则玩家将把所有被展示的牌以随机顺序置入牌库底部。

#### Search **检索**

1. 检索是某些效果中的指示词，告知玩家通览一区域中的一组牌，通常以期达到从该组中选择一张或多张牌，对其进行行动（例如将其移动到另一区域）的结果。

#### Shuffling **洗切**

1. 洗切一组牌是使该一组牌充分地被随机化，使得游戏中任何玩家不能唯一地识别任何一张牌，且就该组之中那些牌中任何一张的位置无合理的认知。
2. 效果可能指示玩家洗切一组牌。若此被做到，则那些玩家必须取出指定的牌或一组牌，并以适合其的随机方式将其混合，直到那些牌被充分地随机化。

#### **Slow 慢速**

1. 慢速是行动牌的性质，决定该牌何时可以被启动。参见时点章节以获取进一步详情。
2. 攻击和伙伴牌固有地具有慢速时点修正，仅能够在没有效果位于效果堆叠上时，由回合玩家在其主要阶段期间被启动。

#### Source **来源**

1. 来源认定为伤害、能力或效果所源自的物件或牌。

#### Suppress **压制**

1. 压制是可以以物件为目标的被关键词化的行动，意为使该能力的操控者"除外该物件并在下一结束阶段开始时将其在其拥有者的操控下移回战场"。该物件的移回由压制所创建的延迟触发引起。
   1. 压制物件的来源的操控者操控该触发。若同时的触发被实例化，则该操控者可以选择这些触发被放置到效果堆叠上的顺序。
2. 若以压制除外的牌在该延迟触发将结算之前将离开除外区，则该延迟触发将不会把该牌从其当前所在的无论何处移回战场；位于除外区的牌必须是起初被除外的同一张牌。
3. 若多个物件被同时压制，则将为每个物件实例化独立的延迟触发，与其他触发分开。若一个压制触发被无效，其将不无效其他任何压制触发。

**召唤**

1. 召唤定义玩家将物件召唤入场的玩家行动。
2. 被召唤的物件被视为仅在战场上存在时有效的衍生。
3. 被召唤的物件（衍生）可用任何游戏外物品代表，但须能将衍生与其他物件轻松区分，且该衍生的特征易于追踪或查阅。

**时间戳**

1. 时间戳是与进入场上的物件绑定的时序标记，或与持续效果在游戏中开始时绑定的时序标记。时间戳用于追踪效果的时效顺序，并在多个效果修改相同数值时决定哪个效果优先生效。
2. 具有时间戳的效果按从旧到新的顺序依次应用。

**衍生**

1. 衍生是通过指示玩家召唤该物件的效果放入场上的物件。
2. 衍生在场上被视为普通物件，但移至其他区域时将不再存在。
3. 移至其他区域的衍生仍会完成所有基于状态的检测、触发及任何必要的操作以结算游戏状态，并在时机被传递给下一位玩家时不再存在。

**转化**

1. 转化定义玩家将一张双面牌（作为物件）翻转至其另一面的玩家行动。只有具有合规可转化面的牌才可以转化。
   1. 若玩家尝试转化无法被转化的牌，则不会发生任何事。这包括试图让一张非双面牌以转化状态进入战场的任何尝试。
2. 转化一张牌将保留最初放置在该物件上的所有指示物。若合规，也将保留所有已应用的持续效果，例如链接。

**单位**

1. 单位是英雄和伙伴物件的统称。
2. 单位通常可在宣告攻击时成为攻击目标。

**唤醒**

1. 要唤醒战场上的物件，需将该物件从水平（待命）方向转为竖直（备战）方向。
2. 已处于备战状态的物件无法再次唤醒；玩家无法对已备战的物件执行唤醒操作。若一个效果尝试唤醒已备战的物件，则不会发生任何事。
