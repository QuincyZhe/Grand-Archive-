# 关键词与能力

在本节中，\[牌名] 指代该牌自身的隐含的名称。

冗余的被关键词化的能力将忽略任何牌或效果上对该能力除第一次以外的提及。

{% hint style="warning" %}
牌的印制上的能力的提示文本可能不会完全体现完整规则中的规则文本条目。提示文本是用于便利地为清晰度和玩家体验的简化的规则。在牌的印制中可能会修改提示文本以精简对更广泛能力的不必要的规则文本。请参考本节以获取精确规则。
{% endhint %}

#### Aethercallin 以太引召

1. 以太引召是卡牌的一种静止式能力，其意思是“当你在进行预视并检视这张牌时，你可以将其装填进一个你操控的以太翼武器中。”
2. 装填一张带有以太引召的卡牌，是作为一个特殊游戏行动来执行的，且不使用效果堆叠。

#### Agility N 敏捷 N

1. 敏捷 N 是延迟触发能力，意为"在结束阶段开始时，将 N 张牌从你的回忆移回你的手牌"。
   1. 赋予玩家敏捷的能力，意为该玩家在一段被确定的持续时间内获取敏捷特性。默认持续时间为一回合。
      1. 玩家可以获取敏捷触发的多个实例。
      2. 玩家的敏捷特性在清理阶段期间作为基于状态的行动失去。
   2. 在其结束阶段开始时，若该玩家具有敏捷，则该能力将为其具备的敏捷的每个实例触发。若多个触发被同时放置到堆叠上，该玩家可以为敏捷触发的结算排序。
2. 你得以挑选哪些牌移回你的手牌。
3. 若你的回忆中的牌小于你可以通过敏捷移回手牌的数量，则你将能移回手牌的尽可能多的牌移回你的手牌。
4. 牌上的敏捷的多个实例将在结束阶段期间生成独立的触发。

#### Ambush 伏击

1. 伏击是单位的固定能力，意为"此单位当其不进行防御期间可以对攻击者反击"。
   1. 伏击允许玩家以该单位反击，当：
      1. 其操控的另一单位被对手攻击。
      2. 对手攻击另一对手所操控的单位。
   2. 当你的单位攻击你操控的另一物件时，伏击将不起作用。
2. 单位必须仍备战才能对攻击者反击。

#### Brew 酿造

1. 酿造是固定能力，允许牌通过使用涉及牺牲原料（通常由采集【链接】召唤）的备选代价被启动。酿造关键词将列出该备选代价所需的物件。
2. 酿造意为"你可以牺牲被列出的物件而非支付此牌的封存代价"。
3. 通过支付备选的酿造代价启动的牌将使该启动成为已酿造。
4. 通过使用酿造代价启动牌仍可以由额外的启动代价修正所修改。在进行酿造牌时忽略修改封存代价的效果。

#### Bulwark 壁垒

1. 壁垒是物件的固定能力，意为"此物件带有一个壁垒指示物进入战场"。
2. 若牌具有壁垒能力的多个实例，则每个能力将使一个壁垒指示物被放置于该物件上。

#### Champion Bonus 英雄奖励

1. 英雄奖励是制限能力，定义牌的奖励效果或替代效果，当且仅当玩家的英雄的传承名称与该制限能力指定的英雄名称相符时启用。
2. 英雄奖励在所有区域中起作用。
3. 若具有英雄奖励能力的牌所列出的英雄的名称与玩家所操控的英雄的名称有差异，使得职业奖励的条件不被符合，则与该奖励相关的关键词和效果作为规则文本的一部分在每个区域中被忽略。

#### Class Bonus 职业奖励

1. 职业奖励是制限能力，定义牌的奖励效果或替代效果，当且仅当玩家的英雄的职业与该牌或物件的职业相符时启用。
2. 为了解锁职业奖励，玩家的英雄必须与该玩家所操控的具有职业奖励的牌上的至少一项职业相符。
3. 职业奖励在所有区域中起作用。
4. 若具有职业奖励的牌与英雄有差异，使得职业奖励的条件不被符合，则与该奖励相关的关键词和效果作为规则文本的一部分在每个区域中被忽略。

{% hint style="info" %}
例如，《Merlin, Memory Thief》从操控《Tristan, Grim Stalker》的玩家的墓场除外《Flame-Rune Swordsman》时，在 Merlin 的能力结算后不获取等级指示物。

#### Class Locked 职业锁定

1. 职业锁定是制限能力，不允许玩家打出该牌，除非该玩家的英雄的职业与该牌的职业相符。
2. 为了解锁该牌，玩家的英雄必须与该玩家所操控的具有职业奖励的牌上的至少一项职业相符。
3. 职业锁定在所有区域中起作用。
4. 若被职业锁定的牌与英雄有差异，使得职业条件不被符合，则该牌不能被打出。
   1. 若牌具有定义不同职业的多个职业锁定能力，则每个制限必须被同时符合，该牌才被允许打出。
5. 与职业奖励或其他与能力绑定的制限能力不同，职业锁定不禁用牌上的规则文本。

#### Cleave ——横扫

1. 横扫是攻击、武器和单位的固定能力，意为"攻击被选定的玩家所操控的所有可被攻击的物件。此攻击不能被拦截"。
   1. 可被攻击的物件包括可攻占领地。
   2. 在宣告期间不选取攻击目标，而是通过选定一名玩家宣告具有横扫的攻击。进行防御的物件基于被选定的玩家所操控的所有合规的可被攻击的物件被分配。任何在进行防御的玩家的操控下进入战场的单位将不被指认为防御者，也不参与作为防御者的战斗。
2. 横扫攻击不能被拦截。

{% hint style="info" %}
例如，对于 1.b，被选定为横扫攻击对象的玩家在战斗的反击步骤开始时启动并结算 Blanche, Sheltering Saint。Blanche 将不认定为进行防御的单位，将不能反击，也不会在伤害步骤期间被造成伤害。

{% endhint %}

3. 具有横扫的攻击可以被每个进行防御的单位反击。
4. 具有横扫的攻击仅涉及一个战斗步骤；伤害同时被造成给每个被分配的进行防御的单位。
   1. 每次伤害计算独立地进行。
5. 作为具有横扫的攻击的结果而被造成的伤害，仅当该武器与该攻击一起使用时，才使该武器上失去一个耐久指示物。
6. 横扫的多个实例是冗余的。

### Critical N 暴击 N

1. 暴击 N 是固定能力，意为“若此将造成战斗伤害，则作为造成战斗伤害的代替将该伤害翻倍，除非对手弃置 N 张牌”。
2. 任何对手可以弃置 N 张牌，即使其操控的单位未受到该伤害。
3. 来自单一来源的暴击的多个实例以累加方式堆叠。例如，同时具有暴击 2 和暴击 3 的伙伴将要求对手以任何组合弃置 2 和 3 张牌，否则该伤害被翻倍。伤害将仅被翻倍一次，无论涉及多少个暴击的实例。

### Command 号令

1. 号令是号令攻击上的固定能力，意为“你操控的伙伴进行此攻击”。
   1. 号令具有被替代的额外代价，即使一个备战的伙伴待命而非英雄。号令能力可以包含指定哪种伙伴类别必须待命的子类别。此替代代价移除使英雄待命以启动攻击牌的代价。
   2. 你无需使你的英雄待命以启动具有号令能力的攻击。
   3. 通过某种形式被免除其使伙伴待命的额外代价的号令——例如通过指定"启动而不支付其代价"的效果——该攻击仍必须选取一个有效的攻击者才能正确地结算；操控者仍必须具有一个伙伴。这将不在攻击期间使该伙伴待命（若其备战），且操控者也可以为以此方式启动的号令选择一个待命状态的伙伴。
2. 在具有号令的攻击结算后，战斗阶段将以处于待命状态的伙伴作为攻击者起始，而非以被选定的英雄。攻击牌被加入处于待命状态的伙伴的意图，作为该战斗阶段的部分。
   1. 在没有有效目标的情况下结算的号令将不创建战斗阶段；处于待命状态的伙伴不会进入战斗。
   2. 伙伴仍必须听从其操控者才能攻击。这意味着若条件（例如傲慢）不被符合，攻击将未能起始，不会有战斗阶段起始，且攻击牌将进入墓场。该伙伴将保持待命状态。
3. 若具有号令能力的攻击牌将被放置到意图中，则攻击者的物件定类将作为基于状态的行动与该能力指定的任何子类别对照检查。若号令能力指定的子类别不被符合，且意图中的号令对该攻击者不是合规的攻击，则该攻击牌将作为基于状态的效果的结果置入墓场。

{% hint style="success" %}
单位将根据其伤害数值及其意图中任何牌的伤害数值造成伤害。
{% endhint %}

### Command Will N 号令意志 N

1. 号令意志是棋兵单位的固定能力，意为“只要此单位在使用号令牌进行攻击，其获得 +N 力量”。
2. 若有号令攻击牌位于其意图区中，则该能力的条件被达成。

### Divine Relic 神圣礼装

1. 神圣礼装是固定能力，意为“你的素材库中只能具有一张带有此关键词的牌”。

#### Efficiency 效率

1. 效率是牌或能力的修正代价的固定能力，意为“启动此牌的代价减少 LV”（LV【链接】指代你的英雄的等级）。
2. 效率仅当牌被放置到效果堆叠上的期间起作用。

#### Element Bonus 属性奖励

1. 属性奖励是制限能力，定义牌的奖励效果或替代效果，当且仅当玩家的英雄的属性与该牌或物件的属性相符时启用。
2. 属性奖励在所有区域中起作用。

#### Empower N 赋能 N

1. 赋能是固定能力，意为“你在此回合中启动的下一张法术牌犹如你的英雄获得 +N 等级般地启动并结算”。
   1. 赋能必须取大于 0 的值才能生效；若效果给予赋能 0，则法术将不被赋能。
2. 赋能在效果堆叠上的牌将要应用之时，固定地被赋予该牌。
   1. 当下一张法术牌被启动时，其以"已赋能"特性被加入效果堆叠，且其所有启动（包括复制）将把进行结算的启动当作已赋能。
3. 赋能的多个实例以累加方式堆叠。

#### Ephemerate 虚化

1. 虚化是固定能力，意为“你可以通过支付其虚化代价从墓场启动此牌”。
   1. 虚化代价由“—”分割。此代价或能力的任何修正在此代价之后被列出。
   2. 由于虚化算作一种未被赋予任何特殊许可或时点机会的备选启动（与星界引召不同），该启动必须遵循该牌的默认速度。
   3. 若该牌经由虚化能力代价被启动，则结算时将成为物件的牌的启动在进入战场时成为虚化状态。
      1. 虚化状态作为物件的特性，修改物件，使得这些物件在每当将离场时被除外。被放置于物件上的虚化状态特性将不被应用于该物件所代表的牌。若该牌将变更区域，该牌不保有“虚化状态”特性，且该牌所代表的任何后续的物件（除非以其他方式指定）将不为虚化状态。
   4. 不会成为物件或意图的牌的启动（例如行动牌），在经由虚化能力代价被启动时，在效果堆叠上成为虚化状态。
      1. 虚化状态作为应用于效果堆叠中的牌的特性，修改这些牌，使得它们在结算时或在将从效果堆叠移动时被除外。
   5. 经由虚化的攻击的启动将成为意图并结算。它们在意图区中认定为虚化状态，且将在战斗结束期间被除外。

{% hint style="success" %}
若效果将除外虚化状态的牌，则该牌仍能追踪该物件，因为其去处未变更。例如，任何形式的临时除外然后移回战场（例如进行压制），将允许该牌移回战场。若以此方式被移回，则其认定为新的物件，且不会“记住”其曾为虚化状态；该新物件不为虚化状态。
{% endhint %}

#### First Boon 恩惠首赐

1. 恩惠首赐是恩惠的固定能力，意为"在游戏开始时、灵魄进入前，赐予此恩惠"。
2. 使用恩惠首赐能力赐予恩惠是游戏前的行动。

#### Floating Memory 遥忆

1. 遥忆是固定能力，意为"当支付回忆代价期间，你可以从你的墓场除外此牌以支付该代价中的 1"。
2. 当支付回忆代价时，作为支付回忆代价的一部分将随机除外若干张牌；以遥忆支付的代价部分必须在决定该数目之前被宣告。
3. 遥忆是冗余的。

#### Fast Activation 快速启动

1. 快速启动是固定能力，意为"你可以以快速的速度启动此牌"。
2. 快速启动是冗余的。

#### Foster 培育

1. 培育是触发能力，意为"在你的追忆阶段开始时，若此伙伴自你的上一回合结束以来未被造成伤害，则其成为培育状态"。
2. 任何单位可以成为培育状态，但单位不能在没有培育关键词的情况下使自身为培育状态。
3. 培育是冗余的。

#### Hindered 受阻

1. 受阻是固定能力，意为"此物件以待命状态进入战场"。
2. 受阻是冗余的。

#### Interdiction **禁绝**

1. 禁绝是牌的固定能力，意为"只要此牌的启动位于效果堆叠上，玩家不能具有时机"。
2. 当具有禁绝的牌被启动时，其将移除玩家具有的任何时机，且时机将不被转移或赋予任何其他玩家。这意味着没有玩家可以打出任何牌、宣告攻击、启动能力，或进行任何出于时点惯例而需要时机的其他玩家行动。
   1. 触发能力仍可以被放置到效果堆叠上。
3. 在具有禁绝的牌的启动结算后，回合玩家将获取时机。

#### Imbue N 注灵 N

1. 注灵是固定能力，意为"当你启动此牌时，你可以封存所有被展示的牌。若其中至少 N 张是<匹配所定义特征的牌>，则此牌成为注灵状态"。
2. 达成注灵能力的条件将使结算的牌或该牌将成为的物件成为注灵状态。
3. 以被展示状态被设定于回忆区中的牌不视为从回忆区被展示。它们只是被以面朝上放置于回忆区中。这意味着其将不会因牌从回忆区被展示而触发。
4. 为注灵展示的牌将在该牌被成功启动并被放置到效果堆叠上之后被翻为面朝下。
5. 若牌具有注灵的多个实例，则只需符合 N 的最小的值即可使该牌成为注灵状态。
6. 若牌具有定义不同特征的注灵能力，则玩家可以选择为哪个特征进行注灵。
7. 注灵可以以下述变体存在：
   1. Imbue N 注灵 N：进行注灵 N 时，所定义的特征默认为匹配注灵状态的牌的属性标识的 N 张牌。
   2. Advanced Imbue N 进阶注灵 N：对于进阶注灵 N，所定义的特征被设定为属于进阶属性的 N 张牌。这些不必匹配该牌的属性。
   3. \[Element] Imbue N \[属性] 注灵 N：这些能力定义一个属性，且 N 张牌需要匹配所定义的属性。

### Immortality ——不朽

1. 不朽是一种静止式能力，其意思是“此物件不能从战场上被送往墓场。”。
   1. 不朽物件不会死亡；它们不会因生命值小于或等于0而进入墓场。
   2. 不朽物件不能被消灭（包括通过牺牲）。
2. 如果一个玩家操控多个同名的独有不朽物件，由于违反了独有规则，作为状态效应，该玩家仍将被迫将其中一个物件置入其墓场。
   1. 此情况算作死亡或被消灭。
3. 不朽是冗余的。

### Inherited effect ——继承效果

1. 继承效果是应用于英雄卡牌上的一种静止式能力，其意思是“只要此牌是其传承的一部分，你的英雄便具有此能力。”。
2. 继承效果仅在该带有此能力的卡牌位于传承区中时生效。

### Intercept ——拦截

1. 拦截是一种触发式能力，其意思是“每当你的英雄被攻击，且此伙伴处于备战状态时，你可以将该次攻击重定向至此伙伴。”。
   1. 该伙伴仍必须是该次攻击的一个有效目标，攻击才能被重定向。
2. 如果一个带有拦截的伙伴不服从一个玩家，则拦截能力的结算将会失败，且该伙伴将无法进行拦截。其触发仍然会发生，并且如果玩家具有任何可能导致该伙伴服从操控玩家的效果，则会呈现时机。
   1. 拦截会触发，但如果该伙伴不服从玩家，则不允许该玩家令该伙伴进行拦截。
3. 拦截是冗余的。

### Kindle N ——点燃 N

1. 点燃是一种静止式能力，其意思是“当你启动此牌时，你可以从你的墓场放逐至多N张火属性卡牌。每放逐一张便支付此牌代价中的1点封存。”。
2. 无论选择以何种方式支付，点燃都不会修正一张卡牌的代价特征。

### Level Restriction ——等级制限

1. 等级限制（格式为带有“等级 N+”的气泡）是一种制限式能力，它会检查一个玩家的英雄是否至少为N级。
2. 等级制限在所有区域均有效。

### Lineage (Keyword) ——传承 （关键词）

1. 传承是用于为英雄升级的一种静止式制限能力，其意思是“\[卡牌名称]必须从一个先前等级的‘X’英雄升级而来”，此处的 X 是先前英雄的角色名称。

{% hint style="info" %}
例如，《洛琳，流浪战士》属于洛琳卡名的英雄，满足升级为《洛琳，剑圣》的条件。

### Lineage Release ——传承解放

1. 传承解放是一种启动式能力，其叙述为“通过从你的英雄的内部传承中放逐此牌来启动此能力。”。
2. 一张卡牌上的传承解放能力，不允许玩家为了支付其上所记载能力的代价，而去放逐另一张带有传承解放能力的卡牌；只有被放逐卡牌的能力的效果，才会被置于效果堆叠上等待结算。
3. 这些能力只有在该带有传承解放的卡牌位于内部传承中（即它不是玩家的英雄）时，才能被启动。

### Link ——链接

1. 链接是物件的一种静止式能力，它可以为处于链接状态的物件赋予类型改变、值或数值修正，或赋予能力。
2. 带有链接能力的物件，在从效果堆叠经结算进入战场上时，会与一个被指定为目标的物件进入链接状态，该目标通常位于“链接”一词之前。
   1. 如果一个带有链接能力的物件将要从效果堆叠以外的区域进入战场上，则在它进入战场上时，只需选择要进入链接状态的物件即可。此过程不指定目标。
   2. 如果带有链接能力的卡牌在启动或具现时没有合规目标，则会失效。如果带有链接能力的物件从效果堆叠以外的区域进入战场上，且没有合规的链接对象可供选择，则它将被牺牲（见第6和第7条）。

{% hint style="info" %}
例如，英雄链接，伙伴链接。链接的目标物件就是那处于链接状态的物件（可被描述为处于链接状态的伙伴，处于链接状态的英雄等）。
{% endhint %}

3. 带有链接能力的卡牌在被置于效果堆-叠上时，必须指定链接目标。如果该目标不再合法，则会失效。
4. 当带有链接能力的物件或处于链接状态的物件任意一方离开战场上时，链接能力便会断开。
5. 如果因处于链接状态的物件以任何方式离开战场上而导致链接被破坏，则带有链接能力的物件会作为一个基于状态的行动被牺牲（玩家必须在任何时机被传递以及任何后续玩家行动被做出之前，将其牺牲）。
6. 一个物件可以处于任意数量的链接能力的效果之下。
7. 只有当至少一个处于链接状态的物件具有一个合规的链接时，链接才存在。

### Memory N+ ——回忆 N+

1. 回忆 N+ 是一种制限式能力，它为一张卡牌定义了一个奖励效果或替代效果，该效果当且仅当玩家的回忆区中具有 N 张或更多卡牌时才被启用。

### On Attack ——攻击时

1. 攻击时是一种触发式能力条件。
2. 在单位上，攻击时的意思是“当此单位攻击时。”。
3. 在意图中的卡牌和武器上，攻击时的意思是“当此项被用于一次攻击中时。”。

### Omnishroud ——全能帷幕

1. 全能帷幕是物件的一种静止式能力，其意思是“此物件不能被启动、具现或触发式能力指定为目标。”
   1. 启动包括卡牌启动和能力启动。
2. 如果一个物件在正被一次启动、具现或触发式能力指定为目标时获得了法术帷幕，该目标将被视为不合规。
   1. 如果该目标是该法术唯一指定的必要目标，则该法术将会失效。
3. 全能帷幕是冗余的。
4. 法术帷幕仍可应用于带有全能帷幕的物件，但由于全能帷幕的限制性更强，指定目标的许可将遵从全能帷幕所设定的规则。

### On Banish ——放逐时

1. 放逐时是一种触发式能力条件，其意思是“当此项被放逐时”。
2. 仅当单位在死亡时直接进入放逐区，才被视为已被放逐；如果该单位因替代效果而被送往任何其他地方，则放逐时不会触发。
3. 放逐时从战场上触发，并将被放逐的那个物件，而非被置入放逐区的那张卡牌本身，视作其能力的来源。

### On Charge N ——充能时 N

1. 充能时是一种触发式能力条件，其意思是“当此物件第一次具有 N 个充能指示物时”。
   1. 该触发式能力只会在第一次具有 N 个充能指示物时触发一次。无论之后充能指示物是否被移除并以某种方式重新获得，它都不会再次触发。
2. 在玩家的追忆步骤开始时，作为基于回合的行动 (TBA)，该玩家在每个带有未触发的“充能时”能力的物件上放置一个充能指示物。

### On Death ——死亡时

1. 死亡时是一种触发式能力条件，其意思是“当此项死亡时”。
   1. 只有单位可以死亡。非单位仍被视为已被消灭，但不被视为已经死亡。
2. 仅当单位在死亡时直接进入墓场，才被视为已经死亡；如果该单位作为被送入墓场的替代而被送入放逐区，则死亡时不会触发。
3. 死亡时从战场上触发，并将死亡的那个物件，而非被置入墓场的那张卡牌本身，视作其能力的来源。

### On Enter ——参战时

1. 参战时是物件的一种触发式能力条件，其意思是“当此项进入战场上时。”。
2. 对于英雄而言，参战时会将进入传承并成为最上方英雄卡牌的那张牌，视作如同该卡牌进入了战场上一样（它不是一个新的物件）。

### On Foster ——培育时

1. 培育时是一种触发式能力条件，其意思是“每当此单位成为培育状态时。”

### On Hit ——命中时

1. 命中时是一种触发式能力条件。
2. 在单位上，命中时的意思是“当此单位对一个可攻击的物件造成战斗伤害时”。
   1. 对一个可攻占的领地造成以该领地失去耐久指示物为形式的伤害，将会触发命中时。
3. 在意图和武器上，命中时的意思是“当使用此项的攻击或反击对一个可攻击的物件造成战斗伤害时”。

{% hint style="info" %}
例如，命中时会在任何单位受到战斗伤害时触发，这通常是通过攻击或反击造成的。命中伙伴时仅在战斗伤害是对一个伙伴单位造成时触发。命中英雄时仅在战斗伤害是对一个英雄单位造成时触发。
{% endhint %}

4. 如果一个命中时能力指定了一个效果，该效果指定了“那个对手”或“那个玩家”，则此语言将指代操控着被命中物件的对手或玩家。

### On Kill ——击杀时

1. 击杀时是一种在被攻击的单位因一次攻击而被击杀时的触发式能力条件。
   1. 单位因生命值小于或等于0，会作为基于状态的效果而被击杀。
   2. 可攻占的领地因耐久小于或等于0，会作为基于状态的效果而被消灭，但由于它们不被视为单位，因此不会触发击杀时。
2. 在单位上，击杀时的意思是“当一个单位因此来源造成的战斗伤害而被击杀时”。
3. 在意图和武器上，击杀时的意思是“当一个单位在一次使用此项的攻击中，因受到战斗伤害而被击杀时。”

### On Leave ——离场时

1. 离场时是一种触发式能力条件，其意思是“当此项离开战场上时”。
2. 离场时从战场上触发，并将离开游戏的那个物件，而非被移至另一个区域的那张卡牌本身，视作其能力的来源。

### Prepare N ——伺机

1. 伺机是一些卡牌上的可选、修正代价的静止式能力，其意思是“作为启动\[卡牌名称]的额外代价，你可以从你的英雄身上移除N个准备指示物。如果你如此做，则\[卡牌名称]在启动时成为伺机状态。”
2. 如果支付了伺机代价，则该卡牌成为“伺机状态”。

### Preserve/Preserved ——留存/留存状态

1. 在物件上，留存的意思是“当\[卡牌名称]被消灭时，将其展示着置入其拥有者的素材库，并使其进入留存状态。当你将要进行具现时，你可以作为替代，将一张处于留存状态的卡牌从你的素材库返回你的手牌。”带有留存的物件在被消灭时会具有一个触发，该触发会导致该物件的卡牌从墓场被送往素材库并进入“留存状态”。
2. 在非物件上，留存的意思是“当\[卡牌名称]结算且将被置入墓场时，改为将其展示着置入其拥有者的素材库，并使其进入留存状态。当你将要进行具现时，你可以作为替代，将一张处于留存状态的卡牌从你的素材库返回你的手牌。”非物件会产生一个替代效果，该效果会在其结算时将该卡牌送往素材库并进入“留存状态”，而非进入墓场。
   1. 如果一张带有留存的非物件卡牌，在结算时将被放逐而非进入墓场，则该牌的操控者可以选择该牌是进入留存状态还是被放逐。
3. 每张进入留存状态的卡牌都是正面朝上地加入素材库，并保持正面朝上，直到它移至手牌、回忆区或其他被认为是非公开信息的区域。
4. “留存状态”是一种卡牌特性，它允许该卡牌在玩家将要具现一张牌时，作为替代被加回该玩家的手牌。
   1. 此行为不会算作一次具现。
   2. 处于留存状态的卡牌在保持留存状态期间，必须保持展示。
   3. 要将一次具现替换为返回一张处于留存状态的卡牌，仅要求玩家被给予一次具现的机会，无论该玩家是否具有能够具现的卡牌。
      1. _“禁止双重获利”_：如果一个许可被给予来“打出”一张牌，那么只有具现这个选项能被替换，玩家在替换具现选项的同时，不能再启动一张卡牌。

### Pride N ——傲慢 N

1. 傲慢是一种静止式能力，其意思是“除非你的英雄等级为N或更高，否则此伙伴不会服从你。”（参见[服从](you-xi-shu-yu.md#obedience)。）。
2. 如果一个物件具有多个傲慢实例，则在决定是否服从时，只将最高的数值纳入考量。

### Ranged N ——远程 N

1. 远程 N 是单位的一种静止式能力，其意思是“只要此单位处于远距状态，其攻击便获得 +N 力量。”
2. 多个远程实例会叠加。

### Renewable ——可再生

1. 可再生是礼装的一种静止式能力，其意思是“如果此牌将要从战场上或意图中被放逐，则改为将其置入其拥有者的素材库。”
2. 可再生不会从任何其他区域生效，例如已装填卡牌的物件特定区域（参见[物件特定区域](../you-xi-ji-zhi/you-xi-ji-zhi-you-xi-qu-yu/you-xi-qu-yu-wu-jian-te-ding-qu-yu.md)）。
3. 可再生是冗余的。

### Reservable ——可封存

1. 可封存是物件的一种静止式能力，其意思是“在支付封存代价时，你可以将此物件置为待命来支付该代价中的 1 点。”。
2. 可封存可以用来支付任何要求封存代价的费用，包括启动代价、附加或额外的封存代价，或被加税的封存代价。
3. 可封存是冗余的。

### Retort N ——回击 N

1. 回击是一种静止式能力，其意思是“只要此伙伴正在进行反击，它便获得 +N 力量。”。

### Spellshroud ——法术帷幕

1. 法术帷幕是物件的一种静止式能力，其意思是“此物件不能被法术指定为目标。”，此处的法术是指具有或被赋予了法术子类型的卡牌、效果或来源。
   1. 由一个法术物件产生的触发本身也属于法术子类型，因此不能指定带有法术帷幕的物件为目标。
2. 如果一个物件在正被一个法术指定为目标时获得了法术帷幕，该目标将被视为不合规。
   1. 如果该目标是该法术唯一指定的必要目标，则该法术将会失效。
3. 法术帷幕是冗余的。

### Starcalling ——星界引召

1. 星界引召是卡牌的一种静止式能力，其意思是“当你在进行预视并检视这张牌时，你可以通过支付此代价来启动它。如果你如此做，将你正在检视的所有其他卡牌以任意顺序置于你的牌库底。”。
   1. 以此方式启动一张卡牌可以忽略其默认的打出速度。
2. 星界引召是启动卡牌的一种替代代价。
3. 当一个玩家使用星界引召代价启动一张卡牌时，该玩家需将进行预视时所见的所有其他卡牌以任意顺序置于牌库底；他们不能选择将任何卡牌置于牌库顶。
4. 星界引召代价仍可被启动代价修正所影响。
5. 星界引召仅在主牌库中生效，且通过支付星界引召代价启动的卡牌，被视为从主牌库而非任何其他区域启动。
6. 一旦一张卡牌通过星界引召被启动，它会被置于效果堆叠上，但直到任何及所有当前正在结算的效果都完全结算完毕后，它才会开始结算。

### Steadfast ——坚毅

1. 坚毅是一种静止式能力，其意思是“此伙伴可以在待命状态下进行反击，且无需因此而待命。”。
2. 坚毅是冗余的。

### Stealth ——潜行

1. 潜行是单位的一种静止式能力，其意思是“除非被真视所允许，否则此物件不能被攻击指定为目标。”。
2. 在获得潜行前已被宣告对一次攻击进行反击的物件，仍将在战斗阶段中对其反击目标进行反击并正常造成伤害。
3. 如果一个物件在正被一次攻击指定为目标时获得了潜行，除非攻击物件具有真视，否则该目标对该次攻击而言被视为不合规，且该次攻击会失效。该防御物件不再是防御物件，该攻击单位也不再是攻击单位。
4. 潜行是冗余的。

### Taunt ——嘲讽

1. 嘲讽是一种静止式能力。
2. 在宣告攻击目标时，如果可能，玩家必须优先选择带有嘲讽且处于备战状态的单位作为目标，而非其他可攻击的物件。
   1. 在最初的攻击宣告之后，攻击仍可被从带有嘲讽的伙伴处重定向或改变。
3. 如果有多个带有嘲讽的物件在场，攻击玩家可以选择攻击其中哪一个单位。
4. 嘲讽是冗余的。一个带有多个嘲讽的物件，其被攻击的优先度不高于一个只带有单个嘲讽实例的物件。

### True Sight ——真视

1. 真视是一种静止式能力。
   1. 在单位上，真视的意思是“此单位的攻击可以指定带有潜行的物件为目标。”。
   2. 在武器上，真视的意思是“使用此武器的攻击可以指定带有潜行的物件为目标。”。
2. 真视是冗余的。

### Unblockable ——贯穿

1. 贯穿是一种静止式能力，其意思是“此单位的攻击不能被拦截且忽略嘲讽。”。
2. 一个贯穿单位的攻击目标仍可被改变（参见[重定向](you-xi-shu-yu.md#redirect)。）
3. 贯穿是冗余的。

### Vigor ——活力

1. 活力是单位的一种触发式能力，其意思是“在你的结束步骤开始时，此单位被唤醒。”。
2. 多个活力实例会在结束步骤产生分别的触发。
