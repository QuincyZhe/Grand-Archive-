# 关键词与能力

在本节中，\[牌名] 指代该牌自身的隐含的名称。

冗余的被关键词化的能力将忽略任何牌或效果上对该能力除第一次以外的提及。

{% hint style="warning" %}
牌的印制上的能力的提示文本可能不会完全体现完整规则中的规则文本条目。提示文本是用于便利地为清晰度和玩家体验的简化的规则。在牌的印制中可能会修改提示文本以精简对更广泛能力的不必要的规则文本。请参考本节以获取精确规则。
{% endhint %}

#### Aethercallin 以太引召

1. 以太引召是卡牌的一种静止式能力，其意思是“当你在进行预视并检视这张牌时，你可以将其装填进一个你操控的以太翼武器中。”
2. 装填一张带有以太引召的卡牌，是作为一个特殊游戏行动来执行的，且不使用效果堆叠。

#### Agility N 敏捷 N

1. 敏捷 N 是延迟触发能力，意为“在结束阶段开始时，将 N 张牌从你的回忆移回你的手牌”。
   1. 赋予玩家敏捷的能力，意为该玩家在一段被确定的持续时间内获取敏捷特性。默认持续时间为一回合。
      1. 玩家可以获取敏捷触发的多个实例。
      2. 玩家的敏捷特性在清理阶段期间作为基于状态的行动失去。
   2. 在其结束阶段开始时，若该玩家具有敏捷，则该能力将为其具备的敏捷的每个实例触发。若多个触发被同时放置到堆叠上，该玩家可以为敏捷触发的结算排序。
2. 你得以挑选哪些牌移回你的手牌。
3. 若你的回忆中的牌小于你可以通过敏捷移回手牌的数量，则你将能移回手牌的尽可能多的牌移回你的手牌。
4. 牌上的敏捷的多个实例将在结束阶段期间生成独立的触发。

#### Ambush 伏击

1. 伏击是单位的固定能力，意为“此单位当其不进行防御期间可以对攻击者反击”。
   1. 伏击允许玩家以该单位反击，当：
      1. 其操控的另一单位被对手攻击。
      2. 对手攻击另一对手所操控的单位。
   2. 当你的单位攻击你操控的另一物件时，伏击将不起作用。
2. 单位必须仍备战才能对攻击者反击。

#### Brew 酿造

1. 酿造是固定能力，允许牌通过使用涉及牺牲原料（通常由采集【链接】召唤）的备选代价被启动。酿造关键词将列出该备选代价所需的物件。
2. 酿造意为“你可以牺牲被列出的物件而非支付此牌的封存代价”。
3. 通过支付备选的酿造代价启动的牌将使该启动成为已酿造。
4. 通过使用酿造代价启动牌仍可以由额外的启动代价修正所修改。在进行酿造牌时忽略修改封存代价的效果。

#### Bulwark 壁垒

1. 壁垒是物件的固定能力，意为“此物件带有一个壁垒指示物进入战场”。
2. 若牌具有壁垒能力的多个实例，则每个能力将使一个壁垒指示物被放置于该物件上。

#### Champion Bonus 英雄奖励

1. 英雄奖励是制限能力，定义牌的奖励效果或替代效果，当且仅当玩家的英雄的传承名称与该制限能力指定的英雄名称相符时启用。
2. 英雄奖励在所有区域中起作用。
3. 若具有英雄奖励能力的牌所列出的英雄的名称与玩家所操控的英雄的名称有差异，使得职业奖励的条件不被符合，则与该奖励相关的关键词和效果作为规则文本的一部分在每个区域中被忽略。

#### Class Bonus 职业奖励

1. 职业奖励是制限能力，定义牌的奖励效果或替代效果，当且仅当玩家的英雄的职业与该牌或物件的职业相符时启用。
2. 为了解锁职业奖励，玩家的英雄必须与该玩家所操控的具有职业奖励的牌上的至少一项职业相符。
3. 职业奖励在所有区域中起作用。
4. 若具有职业奖励的牌与英雄有差异，使得职业奖励的条件不被符合，则与该奖励相关的关键词和效果作为规则文本的一部分在每个区域中被忽略。

{% hint style="info" %}
例如，《Merlin, Memory Thief》从操控《Tristan, Grim Stalker》的玩家的墓场除外《Flame-Rune Swordsman》时，在 Merlin 的能力结算后不获取等级指示物。

#### Class Locked 职业锁定

1. 职业锁定是制限能力，不允许玩家打出该牌，除非该玩家的英雄的职业与该牌的职业相符。
2. 为了解锁该牌，玩家的英雄必须与该玩家所操控的具有职业奖励的牌上的至少一项职业相符。
3. 职业锁定在所有区域中起作用。
4. 若被职业锁定的牌与英雄有差异，使得职业条件不被符合，则该牌不能被打出。
   1. 若牌具有定义不同职业的多个职业锁定能力，则每个制限必须被同时符合，该牌才被允许打出。
5. 与职业奖励或其他与能力绑定的制限能力不同，职业锁定不禁用牌上的规则文本。

#### Cleave 横扫

1. 横扫是攻击、武器和单位的固定能力，意为“攻击被选定的玩家所操控的所有可被攻击的物件。此攻击不能被拦截”。
   1. 可被攻击的物件包括可攻占领地。
   2. 在宣告期间不选取攻击目标，而是通过选定一名玩家宣告具有横扫的攻击。进行防御的物件基于被选定的玩家所操控的所有合规的可被攻击的物件被分配。任何在进行防御的玩家的操控下进入战场的单位将不被指认为防御者，也不参与作为防御者的战斗。
2. 横扫攻击不能被拦截。

{% hint style="info" %}
例如，对于 1.b，被选定为横扫攻击对象的玩家在战斗的反击步骤开始时启动并结算 Blanche, Sheltering Saint。Blanche 将不认定为进行防御的单位，将不能反击，也不会在伤害步骤期间被造成伤害。

{% endhint %}

3. 具有横扫的攻击可以被每个进行防御的单位反击。
4. 具有横扫的攻击仅涉及一个战斗步骤；伤害同时被造成给每个被分配的进行防御的单位。
   1. 每次伤害计算独立地进行。
5. 作为具有横扫的攻击的结果而被造成的伤害，仅当该武器与该攻击一起使用时，才使该武器上失去一个耐久指示物。
6. 横扫的多个实例是冗余的。

#### Critical N 暴击 N

1. 暴击 N 是固定能力，意为“若此将造成战斗伤害，则作为造成战斗伤害的代替将该伤害翻倍，除非对手弃置 N 张牌”。
2. 任何对手可以弃置 N 张牌，即使其操控的单位未受到该伤害。
3. 来自单一来源的暴击的多个实例以累加方式堆叠。例如，同时具有暴击 2 和暴击 3 的伙伴将要求对手以任何组合弃置 2 和 3 张牌，否则该伤害被翻倍。伤害将仅被翻倍一次，无论涉及多少个暴击的实例。

#### Command 号令

1. 号令是号令攻击上的固定能力，意为“你操控的伙伴进行此攻击”。
   1. 号令具有被替代的额外代价，即使一个备战的伙伴待命而非英雄。号令能力可以包含指定哪种伙伴类别必须待命的子类别。此替代代价移除使英雄待命以启动攻击牌的代价。
   2. 你无需使你的英雄待命以启动具有号令能力的攻击。
   3. 通过某种形式被免除其使伙伴待命的额外代价的号令——例如通过指定"启动而不支付其代价"的效果——该攻击仍必须选取一个有效的攻击者才能正确地结算；操控者仍必须具有一个伙伴。这将不在攻击期间使该伙伴待命（若其备战），且操控者也可以为以此方式启动的号令选择一个待命状态的伙伴。
2. 在具有号令的攻击结算后，战斗阶段将以处于待命状态的伙伴作为攻击者起始，而非以被选定的英雄。攻击牌被加入处于待命状态的伙伴的意图，作为该战斗阶段的部分。
   1. 在没有有效目标的情况下结算的号令将不创建战斗阶段；处于待命状态的伙伴不会进入战斗。
   2. 伙伴仍必须服从其操控者才能攻击。这意味着若条件（例如傲慢）不被符合，攻击将未能起始，不会有战斗阶段起始，且攻击牌将进入墓场。该伙伴将保持待命状态。
3. 若具有号令能力的攻击牌将被放置到意图中，则攻击者的物件定类将作为基于状态的行动与该能力指定的任何子类别对照检查。若号令能力指定的子类别不被符合，且意图中的号令对该攻击者不是合规的攻击，则该攻击牌将作为基于状态的效果的结果置入墓场。

{% hint style="success" %}
单位将根据其伤害数值及其意图中任何牌的伤害数值造成伤害。
{% endhint %}

#### Command Will N 号令意志 N

1. 号令意志是棋兵单位的固定能力，意为“只要此单位在使用号令牌进行攻击，其获得 +N 力量”。
2. 若有号令攻击牌位于其意图区中，则该能力的条件被达成。

#### Divine Relic 神圣礼装

1. 神圣礼装是固定能力，意为“你的素材库中只能具有一张带有此关键词的牌”。

#### Efficiency 效率

1. 效率是牌或能力的修正代价的固定能力，意为“启动此牌的代价减少 LV”（LV【链接】指代你的英雄的等级）。
2. 效率仅当牌被放置到效果堆叠上的期间起作用。

#### Element Bonus 属性奖励

1. 属性奖励是制限能力，定义牌的奖励效果或替代效果，当且仅当玩家的英雄的属性与该牌或物件的属性相符时启用。
2. 属性奖励在所有区域中起作用。

#### Empower N 赋能 N

1. 赋能是固定能力，意为“你在此回合中启动的下一张法术牌犹如你的英雄获得 +N 等级般地启动并结算”。
   1. 赋能必须取大于 0 的值才能生效；若效果给予赋能 0，则法术将不被赋能。
2. 赋能在效果堆叠上的牌将要应用之时，固定地被赋予该牌。
   1. 当下一张法术牌被启动时，其以"已赋能"特性被加入效果堆叠，且其所有启动（包括复制）将把进行结算的启动当作已赋能。
3. 赋能的多个实例以累加方式堆叠。

#### Ephemerate 虚化

1. 虚化是固定能力，意为“你可以通过支付其虚化代价从墓场启动此牌”。
   1. 虚化代价由“—”分割。此代价或能力的任何修正在此代价之后被列出。
   2. 由于虚化算作一种未被赋予任何特殊许可或时点机会的备选启动（与星界引召不同），该启动必须遵循该牌的默认速度。
   3. 若该牌经由虚化能力代价被启动，则结算时将成为物件的牌的启动在进入战场时成为虚化状态。
      1. 虚化状态作为物件的特性，修改物件，使得这些物件在每当将离场时被除外。被放置于物件上的虚化状态特性将不被应用于该物件所代表的牌。若该牌将变更区域，该牌不保有“虚化状态”特性，且该牌所代表的任何后续的物件（除非以其他方式指定）将不为虚化状态。
   4. 不会成为物件或意图的牌的启动（例如行动牌），在经由虚化能力代价被启动时，在效果堆叠上成为虚化状态。
      1. 虚化状态作为应用于效果堆叠中的牌的特性，修改这些牌，使得它们在结算时或在将从效果堆叠移动时被除外。
   5. 经由虚化的攻击的启动将成为意图并结算。它们在意图区中认定为虚化状态，且将在战斗结束期间被除外。

{% hint style="success" %}
若效果将除外虚化状态的牌，则该牌仍能追踪该物件，因为其去处未变更。例如，任何形式的临时除外然后移回战场（例如进行压制），将允许该牌移回战场。若以此方式被移回，则其认定为新的物件，且不会“记住”其曾为虚化状态；该新物件不为虚化状态。
{% endhint %}

#### First Boon 恩惠首赐

1. 恩惠首赐是恩惠的固定能力，意为“在游戏开始时、灵魄进入前，赐予此恩惠”。
2. 使用恩惠首赐能力赐予恩惠是游戏前的行动。

#### Floating Memory 遥忆

1. 遥忆是固定能力，意为“当支付回忆代价期间，你可以从你的墓场除外此牌以支付该代价中的 1”。
2. 当支付回忆代价时，作为支付回忆代价的一部分将随机除外若干张牌；以遥忆支付的代价部分必须在决定该数目之前被宣告。
3. 遥忆是冗余的。

#### Fast Activation 快速启动

1. 快速启动是固定能力，意为“你可以以快速的速度启动此牌”。
2. 快速启动是冗余的。

#### Foster 培育

1. 培育是触发能力，意为“在你的追忆阶段开始时，若此伙伴自你的上一回合结束以来未被造成伤害，则其成为培育状态”。
2. 任何单位可以成为培育状态，但单位不能在没有培育关键词的情况下使自身为培育状态。
3. 培育是冗余的。

#### Hindered 受阻

1. 受阻是固定能力，意为“此物件以待命状态进入战场”。
2. 受阻是冗余的。

#### Interdiction **禁绝**

1. 禁绝是牌的固定能力，意为“只要此牌的启动位于效果堆叠上，玩家不能具有时机”。
2. 当具有禁绝的牌被启动时，其将移除玩家具有的任何时机，且时机将不被转移或赋予任何其他玩家。这意味着没有玩家可以打出任何牌、宣告攻击、启动能力，或进行任何出于时点规定而需要时机的其他玩家行动。
   1. 触发能力仍可以被放置到效果堆叠上。
3. 在具有禁绝的牌的启动结算后，回合玩家将获取时机。

#### Imbue N 注灵 N

1. 注灵是固定能力，意为“当你启动此牌时，你可以封存所有被展示的牌。若其中至少 N 张是<匹配所定义特征的牌>，则此牌成为注灵状态”。
2. 达成注灵能力的条件将使结算的牌或该牌将成为的物件成为注灵状态。
3. 以被展示状态被设定于回忆区中的牌不视为从回忆区被展示。它们只是被以面朝上放置于回忆区中。这意味着其将不会因牌从回忆区被展示而触发。
4. 为注灵展示的牌将在该牌被成功启动并被放置到效果堆叠上之后被翻为面朝下。
5. 若牌具有注灵的多个实例，则只需符合 N 的最小的值即可使该牌成为注灵状态。
6. 若牌具有定义不同特征的注灵能力，则玩家可以选择为哪个特征进行注灵。
7. 注灵可以以下述变体存在：
   1. Imbue N 注灵 N：进行注灵 N 时，所定义的特征默认为匹配注灵状态的牌的属性标识的 N 张牌。
   2. Advanced Imbue N 进阶注灵 N：对于进阶注灵 N，所定义的特征被设定为属于进阶属性的 N 张牌。这些不必匹配该牌的属性。
   3. \[Element] Imbue N \[属性] 注灵 N：这些能力定义一个属性，且 N 张牌需要匹配所定义的属性。

#### Immortality 不朽

1. 不朽是固定能力，意为“此物件不能从战场被送入墓场”。
   1. 不朽的物件不死亡；它们不会因为具有 0 或更少的生命而去往墓场。
   2. 不朽的物件不能被消灭（包括经由牺牲）。
2. 若玩家操控具有相同名称的多个独有的不朽物件，则该玩家仍将作为违反独有规则的结果，作为基于状态的效果被强制将这些物件之一置入其墓场。
   1. 规则 2 优先于规则 1，并允许在这些情况下忽略规则 1。
   2. 这算作死亡或被消灭。
3. 不朽是冗余的。

#### Inherited effect 继承效果

1. 继承效果是应用于英雄牌的固定能力，意为“只要此牌为其传承的一部分，你的英雄具有此能力”。
2. 继承效果仅当具有该能力的牌位于传承中期间起作用。

#### Intercept 拦截

1. 拦截是触发能力，意为“每当你的英雄在此伙伴备战时被攻击，你可以将该攻击重定向至此伙伴”。
   1. 该伙伴仍必须是有效目标，该攻击才能被重定向。
2. 若具有拦截的伙伴不服从玩家，则拦截能力的结算将失败且该伙伴将不能拦截。触发仍发生，且若玩家具有可能使该伙伴服从操控的玩家的任何效果，则时机被提供。
   1. 拦截触发后，若该伙伴不服从该玩家，则将不允许该玩家使该伙伴拦截。
3. 拦截是冗余的。

#### Kindle N 点燃 N

1. 点燃是固定能力，意为“当你启动此牌时，你可以从你的墓场除外最多 N 张火属性牌。其中每一张支付1点此牌代价的封存”。
2. 无论其支付如何被选用，点燃都不修改牌的代价特征。

#### Level Locked N 等级锁定 N

1. 等级锁定是制限能力，不允许玩家打出该牌，除非该玩家的英雄的基本（书面）等级至少为 N 或以上。
2. 为了解锁该牌，玩家的英雄牌必须提供 N 或以上的等级；来自持续效果的等级修正将不对改变英雄的基本等级起作用。
3. 等级锁定在所有区域中起作用。
4. 若牌被等级锁定，且英雄的等级不足以达到必备的 N，则该牌不能被打出。
   1. 若牌具有多个等级锁定能力，则最高的制限必须被符合，该牌才被允许打出。
5. 与职业奖励或其他与能力绑定的制限能力不同，等级锁定不禁用牌上的规则文本。

#### Level Restriction 等级制限

1. 等级制限（以带有 Level N+ 的圆框的格式呈现）是检查玩家的英雄是否至少为等级 N 的制限能力。
2. 等级制限在所有区域中起作用。

#### Lineage (Keyword)  传承 （关键词）

1. 传承是用于使英雄升级的固定制限能力，意为“\[牌名] 必须从上一等级‘X’英雄升级而来”，其中 X 是上一英雄的角色名称。

{% hint style="info" %}
例如，Lorraine, Wandering Warrior 是 Lorraine 英雄，且将是升级为 Lorraine, Blademaster 的有效条件。

#### Lineage Release 传承解放

1. 传承解放是启动能力，意为“通过从你的英雄的内部传承除外此牌来启动此能力”。
2. 一张牌上的传承解放能力不允许玩家为该书面能力的代价除外另一张具有传承解放能力的牌；只有被除外的牌的能力的效果将被放置到效果堆叠上等待结算。
3. 这些能力仅当具有传承解放的牌位于内部传承中（即其不是玩家的英雄）时才能被启动。

#### Link 链接

1. 链接是物件的固定能力，意为“此物件链接至一个目标物件地进入战场。若该链接被断开，牺牲此物件”。
   1. 该链接将指认一个作为该链接的目标（或，有时，是选择）的被链接的物件。
   2. 链接能力可以以物件类别作为前缀。这将限制链接能力，使其在定为目标时只将该类别的物件认定为合规的。这对于选择而言同样成立。
2. 在从效果堆叠结算之后进入战场且指定链接能力的物件，成为链接至一个被定为目标的物件，该物件通常置于 Link 一词之前。
   1. 若具有链接能力的物件将从效果堆叠以外的区域进入战场，则被链接的物件只是在该物件进入战场时被选择。其将不以任何事物为目标。
   2. 若具有链接能力的牌的启动或具现没有合规的目标，则其将失效。若具有链接能力的物件从效果堆叠以外的区域进入战场且没有合规的链接对象选择，则其将被牺牲（见第 6 和第 7 点）。

{% hint style="info" %}
例如，英雄链接、伙伴链接。链接的目标物件是被链接的物件（且可以被描述为被链接的伙伴、被链接的英雄等）。
{% endhint %}

3. 具有链接能力的牌在被放置到效果堆叠上时必须指定链接目标。若该物件不再合规，则其将失效。
4. 当具有链接能力的物件或被链接的物件离场时，链接能力被断开。若链接在任何时候变为不合规——例如通过类别变更或类别设定——则该链接也被断开。
5. 若具有链接能力的物件在基于状态的检查期间与某物件没有链接，则具有链接能力的物件作为基于状态的行动被牺牲（玩家必须在任何时机被传递、任何进一步的玩家行动被进行之前牺牲它）。这考虑链接在具有链接能力的物件进入战场时是否被断开或不存在。
6. 物件可以受任意数目的链接能力的效果影响。
7. 链接仅当至少一个被链接的物件具有合规的链接时存在。

#### Memory N+ 回忆 N+

1. 回忆 N+ 是制限能力，定义牌的奖励效果或替代效果，当且仅当玩家在其回忆区中具有 N 张或更多的牌时启用。

#### Omnishroud 全域遮断

1. 全域遮断是物件的固定能力，意为“此不能被启动、具现或触发能力定为目标”。
   1. 启动包括牌启动和能力启动。
2. 若物件在被启动、具现或触发能力定为目标期间获得全域遮断，则该目标将认定为不合规。
   1. 若该目标是被法术唯一被指定的必要目标，则该法术将失效。
3. 全域遮断是冗余的。
4. 法术遮断仍可以被应用于具有全域遮断的物件，但将遵从全域遮断所设定的定为目标的许可，因为全域遮断限制性更强。

#### On Attack 攻击时

1. 攻击时是触发能力的条件。
2. 在单位上，攻击时意为“当此单位攻击时”。
3. 在意图中的牌上和武器上，攻击时意为“当此被用于攻击时”。

#### On Banish 放逐时

1. 除外时是触发能力的条件，意为“当此被除外时”。
2. 单位仅当其在死亡时直接去往除外区时才认定为被除外；若该单位因替代效果而被送入其他任何地方，则除外时将不触发。
3. 除外时从战场触发，且将该能力的来源认定为被除外的物件，而非被放置于除外区的牌本身。

#### On Charge N 充能 N 时

1. 充能时是触发能力的条件，意为“此物件首次具有 N 个充能指示物时”。
   1. 该触发能力将仅触发一次，即首次具有 N 个充能指示物时。无论充能指示物是否被移除并且其以某种方式重新获取充能指示物，其将不再触发。
2. 在玩家追忆步骤开始时，作为基于回合的行动（TBA），该玩家在其每一个具有未触发充能时能力的物件上放置一个充能指示物。

#### On Death 死亡时

1. 死亡时是触发能力的条件，意为“当此死亡时”。
   1. 仅单位可以死亡。非单位仍认定为被消灭，但不认定为已死亡。
2. 单位仅当其在死亡时直接去往墓场时才认定为已死亡；若该单位因被送入墓场的替代而被送入除外区，则死亡时将不触发。
3. 死亡时从战场触发，且将该能力的来源认定为死亡的物件，而非被放置于墓场的牌本身。

#### On Enter 参战时

1. 参战时是物件的触发能力的条件，意为“当此进入战场时”。
2. 对于英雄，参战时将进入传承的牌认定为最顶端的英雄牌，犹如该牌已进入战场（其不是新的物件）。

#### On Foster 培育时

1. 培育时是触发能力的条件，意为“每当此单位成为培育状态时”。

#### On Hit 命中时

1. 命中时是触发能力的条件。
2. 在单位上，命中时意为"当此对可被攻击的物件造成战斗伤害时"。
   1. 命中时将因以从可攻占领地失去耐久指示物的形式造成的伤害命中该领地而触发。
3. 在意图和武器上，命中时意为“当使用此进行的攻击或反击对可被攻击的物件造成战斗伤害时”。

{% hint style="info" %}
例如，命中时因任何单位被造成战斗伤害——通常通过攻击或反击——而触发。命中伙伴时仅当战斗伤害被造成给伙伴单位时触发。命中英雄时仅当战斗伤害被造成给英雄单位时触发。
{% endhint %}

4. 若命中时能力指定的效果指定“该对手”或“该玩家”，此用语将指定操控被命中的物件的对手或玩家。

#### On Kill 击杀时

1. 击杀时是当被攻击的单位因攻击而被击杀时的触发能力的条件。
   1. 单位因具有 0 或更少的生命作为基于状态的效果而被击杀。
   2. 可攻占领地因具有 0 或更少的耐久作为基于状态的效果而被消灭，但将不触发击杀时，因为它们不认定为单位。
2. 在单位上，击杀时意为“当单位因被此造成战斗伤害而被击杀时”。
3. 在意图和武器上，击杀时意为“当单位因在使用此进行的攻击中被造成战斗伤害而被击杀时”。

{% hint style="success" %}
参见已死亡：“单位当且仅当其直接从场上进入墓场时，才认定为已死亡或被击杀。”。这意味着击杀时将仅当该单位因被造成的战斗伤害直接去往墓场时触发，而不通过任何连带效果（例如之后将击杀该单位的命中时能力）触发。
{% endhint %}

#### On Leave 离场时

1. 离场时是触发能力的条件，意为“当此离场时”。
2. 离场时从战场触发，且将该能力的来源认定为离开场上的物件，而非被移动到另一区域的牌本身。

#### Prepare N 伺机

1. 伺机是某些牌的可选的修正代价的固定能力，意为“作为启动 \[牌名] 的额外代价，你可以从你的英雄移除 N 个准备指示物。若你如此做，\[牌名] 当其被启动之际成为伺机状态”。
2. 若伺机代价被支付，则该牌成为“伺机状态”。

#### Preserve/Preserved 留存/留存状态

1. 留存在物件上是触发能力，意为“当 \[牌名] 被消灭时，将其以被展示状态且为留存状态置入其拥有者的素材库。当你将具现时，你可以将一张留存状态的牌从你的素材库移回你的手牌，以代替具现。”。具有留存的物件将在它们被消灭时具有触发，该触发将使该物件的牌以“留存状态”被从墓场送入素材库。
   1. 若牌作为去往墓场的代替而被除外，其不位于墓场仍将触发留存。
2. 留存在非物件上是固定能力，意为“当 \[牌名] 结算之际且将被置入墓场，则作为代替将其以被展示状态且为留存状态置入其拥有者的素材库。当你将具现时，你可以将一张留存状态的牌从你的素材库移回你的手牌，以代替具现。”。非物件将生成替代效果，该替代效果将使该牌结算之际以“留存状态”被送入素材库，而非进入墓场。
   1. 若具有留存的非物件牌结算之际将作为去往墓场的代替而被除外，则该牌的操控者可以选择该牌是为留存状态还是被除外。
3. 每张为留存状态的牌都被以面朝上添加到素材库，并保持面朝上直到其移动到手牌、回忆或其他认定为私有信息的区域。
4. “留存状态”是一种牌的特性，允许该牌在玩家将具现时被加回到该玩家的手牌，以代替具现一张牌。
   1. 这将不算作一次具现。
   2. 只要留存状态的牌保持为留存状态，它们就必须保持被展示。
   3. 移回留存状态的牌以替代具现，仅需要玩家有某一个具现的时机，无论该玩家是否具有其能够具现的牌。
      1. _“禁止双重得利”_：若被给予“打出”一张牌的许可，则只有具现的选择可以被替代，玩家不能在替代具现的选项的同时启动一张牌。

#### Pride N 傲慢 N

1. 傲慢是固定能力，意为“除非你的英雄等级为 N 或以上，否则此伙伴将不服从你。”（参照服从。）
2. 若物件具有傲慢的多个实例，则仅最高的值被纳入考虑以决定服从。

#### Ranged N 远程 N

1. 远程 N 是单位的固定能力，意为“只要此单位处于远离状态，其攻击获得 +N 力量”。
2. 远程的多个实例以累加方式堆叠。

#### Renewable 可再生

1. 可再生是礼装的固定能力，意为“若此牌将从战场或意图被除外，则作为代替将其置入其拥有者的素材库”。
2. 可再生将不从任何其他区域起作用，例如已装填牌的专属物件区（参见专属物件区）。
3. 可再生是冗余的。

#### Reservable 可封存

1. 可封存是物件的固定能力，意为“当支付封存代价期间，你可以使此物件待命以支付 1 点该代价”。
2. 可封存可以支付需要封存代价的任何代价，包括启动代价、被添加的或附加的封存代价、或被加征的封存代价。
3. 可封存是冗余的。

#### Retort N 回击 N

1. 回击是固定能力，意为“只要此伙伴在进行反击，其获得 +N 力量”。

#### Spellshroud 法术遮断

1. 法术遮断是物件的固定能力，意为“此不能被法术定为目标”，此处的法术是具有或被赋予法术子类别的牌、效果或来源。
   1. 由法术物件生成的触发自身亦为法术子类别，因此不能将具有法术遮断的物件定为目标。
2. 若物件在被法术定为目标期间获得法术遮断，则该目标将认定为不合规。
   1. 若该目标是该法术唯一被指定的必要目标，则该法术将失效。
3. 法术遮断是冗余的。

#### Starcalling 星界引召

1. 星界引召是牌的固定能力，意为“当你在预视时查看此牌之际，你可以通过支付此代价启动其。若你如此做，将你所查看的所有其他牌以任意顺序置于你的牌库底部”。
   1. 以此方式启动牌可以忽略默认打出速度。
2. 星界引召是用于启动牌的备选代价。
3. 当玩家使用星界引召代价启动牌时，该玩家将其在预视时看到的所有其他牌以任意顺序置于牌库底部；其不可以选择将任何牌置于牌库顶部。
4. 星界引召代价仍可以被启动代价修正所修改。
5. 星界引召仅从主牌库起作用，且通过支付星界引召代价启动的牌认定为从主牌库被启动，而非任何其他区域。
6. 一旦牌经由星界引召被启动，其将被放置到效果堆叠上，但直到任何及所有当前进行结算的效果完全结算后才开始结算。

#### Steadfast 坚毅

1. 坚毅是固定能力，意为“此伙伴在待命状态时可以反击，且如此做不使其待命”。
2. 坚毅是冗余的。

#### Stealth 潜行

1. 潜行是单位的固定能力，意为“此单位不能被攻击定为目标，除非已有真视许可”。
2. 在获得潜行之前被宣告为对攻击进行反击的物件，仍将对其反击目标反击，且将在战斗阶段期间相应地造成伤害。
3. 若物件在作为攻击的目标期间获得潜行，则该目标对该攻击认定为不合规，且该攻击失效，除非进行攻击的物件具有真视。进行防御的物件不再是进行防御的物件。
4. 潜行是冗余的。

#### Taunt 嘲讽

1. 嘲讽是单位的固定能力，意为“在备战状态时，若可能，此必须在你的对手的攻击宣告期间被先于你操控的其他物件定为目标”。
2. 当为攻击宣告目标时，若可能，玩家必须相较于其他可被攻击的物件，将具有嘲讽的备战单位定为目标。
   1. 攻击在最初的攻击宣告之后可以被重定向，或从具有嘲讽的伙伴被变更。
3. 若多个具有嘲讽的物件位于场上，则进行攻击的玩家可以选择对这些单位中的哪一个进行攻击。
4. 嘲讽是冗余的。相较于具有单一实例的嘲讽的物件，不必更优先地攻击具有多个实例的嘲讽的物件。

#### True Sight 真视

1. 真视是固定能力。
   1. 在单位上，真视意为“此单位的攻击可以将具有潜行的单位定为目标”。
   2. 在武器上，真视意为“使用此武器进行的攻击可以将具有潜行的单位定为目标”。
   3. 在攻击上，真视意为“此攻击可以将具有潜行的单位定为目标”。
2. 真视是冗余的。

#### Unblockable 贯穿

1. 贯穿是固定能力，意为“此单位的攻击不能被拦截且忽略嘲讽”。
2. 来自具有贯穿的单位的攻击目标仍可以被变更（参见重定向）。
3. 贯穿是冗余的。

#### Vigor 活力

1. 活力是单位的触发能力，意为“此单位在你的结束步骤开始时唤醒”。
2. 活力的多个实例将在结束步骤期间创建分开的触发。
