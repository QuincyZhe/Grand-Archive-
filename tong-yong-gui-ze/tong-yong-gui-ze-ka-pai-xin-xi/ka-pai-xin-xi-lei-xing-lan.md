# 牌的组成部分 - 类别栏

通用规则：

1. 牌具有列于牌的中间区段左侧的类别栏中的牌类别。这些类别为[英雄](../tong-yong-gui-ze-ka-pai-lei-xing/ka-pai-lei-xing-ying-xiong.md)、[伙伴](../tong-yong-gui-ze-ka-pai-lei-xing/ka-pai-lei-xing-huo-ban.md)、[行动](../tong-yong-gui-ze-ka-pai-lei-xing/ka-pai-lei-xing-xing-dong.md)、[攻击](../tong-yong-gui-ze-ka-pai-lei-xing/ka-pai-lei-xing-gong-ji.md)、[武器](../tong-yong-gui-ze-ka-pai-lei-xing/ka-pai-lei-xing-wu-qi.md)、[领地](../tong-yong-gui-ze-ka-pai-lei-xing/ka-pai-lei-xing-ling-di.md)、[道具](../tong-yong-gui-ze-ka-pai-lei-xing/ka-pai-lei-xing-dao-ju.md)和[幻象](../tong-yong-gui-ze-ka-pai-lei-xing/ka-pai-lei-xing-huan-xiang.md)。
   1. 默认地，英雄牌具有生命数值；伙伴牌具有力量数值和生命数值二者；行动牌具有速度数值；武器牌具有力量数值和耐久数值二者；攻击牌具有力量数值。
   2. [功能性子类别](../tong-yong-gui-ze-ka-pai-lei-xing/ka-pai-lei-xing-gong-neng-xing-zi-lei-xing.md)可以赋予通常不见于这些牌类别的额外数值。
2. 伙伴、行动、武器和攻击牌通常具有职业子类别。
   1. 职业子类别是类别栏上被列出的第一个子类别。
   2. 牌可以具有多个子类别，其中多个职业子类别由"/"分隔。
   3. 无论职业定类如何，牌都可以被启动。

{% hint style="info" %}
例如，玩家可以启动刺客牌，即使其英雄是战士。
{% endhint %}

3. 牌有时具有特征子类别，例如"回应"、"技能"、"和谐"或"旋律"。这些特征可以被能力参照，作为特定效果的条件。
