# 牌的组成部分 - 属性

通用规则：

1. 所有牌都具有标示于牌的右上方的属性。
   1. 若牌或物件未被指定具有属性，则其默认为无属性。
2. 牌上指定的属性必须对该玩家启用，该玩家才能打出该牌。
   1. 无属性固有地对所有玩家解锁。
   2. 英雄牌在具现时不受属性制限的约束。
3. 非无属性固有地依据传承之内的英雄牌的属性而解锁（见[传承](../../yong-yu-ji/you-xi-shu-yu.md#lineage-term-chuan-cheng-shu-yu)）；非英雄牌不解锁属性。

{% hint style="success" %}
例如，玩家的传承中包含一张 Spirit of Water、无属性英雄和一张奥术英雄；该玩家可以打出或启动无、水和奥术属性的牌。
{% endhint %}

{% hint style="success" %}
例如，只要使该英雄升级的其他规则被遵循，玩家可以具现一个具有极星属性类别的等级 3 英雄，而无需先前已启用极星属性。
{% endhint %}

4. 基础属性为火、水和风属性；进阶属性为任何不是火、水、风或无的属性。崇高为只要你启用任一进阶属性便默认解锁的特殊进阶属性。
