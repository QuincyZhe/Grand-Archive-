# 卡牌信息 - 属性

通用规则：

1. 所有卡牌在卡牌的右上方均标示有一个属性。
   1. 如果一张卡牌或物件未被指定具有一个属性，它默认为常规。
2. 卡牌上指定的属性必须为一名玩家启用，该玩家才能打出该卡牌。
   1. 常规属性对所有玩家固有解锁。
   2. 英雄卡牌在具现时不受属性制限的约束。
3. 非常规属性根据传承（见[传承](../../yong-yu-ji/you-xi-shu-yu.md#lineage-term-chuan-cheng-shu-yu)）内英雄卡牌的属性固有解锁；非英雄卡牌不解锁属性。

{% hint style="success" %}
例如，一名玩家拥有包含水灵魄、常规英雄和一个奥术英雄的传承；该玩家可以打出或启动常规、水和奥术卡牌。
{% endhint %}

{% hint style="success" %}
例如，一名玩家可以具现一个具有极星属性类别的等级 3 英雄，而无需先前启用极星属性，只要遵循升级该英雄的其他规则。
{% endhint %}

4. 基础属性是火、水和风属性；进阶属性是任何非火、水、风或常规的属性。崇高是一个特殊进阶属性，只要你拥有一个启用另一个进阶属性的英雄，它就会默认解锁。
