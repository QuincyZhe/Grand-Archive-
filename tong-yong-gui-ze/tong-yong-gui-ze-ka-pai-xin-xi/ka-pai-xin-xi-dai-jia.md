# 牌的组成部分 - 代价

牌的基本代价被指示于牌的左上方。

通用规则：

1. 代价分为封存代价和回忆代价；封存代价由黄色代表，而回忆代价由蓝色代表。

{% hint style="success" %}
牌的"代价"，当其规则文本中被提及时，指代的是在该牌中被体现的代价类别。英雄的回忆代价位于其印刷等级下方。
{% endhint %}

2. 若数字为封存代价，则其代表需封存的牌的数目；作为该代价的支付，那个数目的牌必须从该玩家的手牌被面朝下放入[回忆区](../../you-xi-ji-zhi/you-xi-ji-zhi-you-xi-qu-yu/you-xi-qu-yu-hui-yi.md)（也称为回忆），并[封存](../../yong-yu-ji/you-xi-shu-yu.md#reserve-feng-cun)直到下一次追忆。
   1. 在为支付封存代价而选择牌的时间与那些牌被面朝下放入回忆的时间之间，玩家不被给予时机，且不可以采取玩家行动。

{% hint style="warning" %}
为支付封存代价，从你的手牌选取 X 张其他牌（其中 X 是意欲启动的牌所需要的代价），并将其面朝下放入你的回忆区。
{% endhint %}

3. 若数字为回忆代价，则该代价必须通过从[回忆区](../../you-xi-ji-zhi/you-xi-ji-zhi-you-xi-qu-yu/you-xi-qu-yu-hui-yi.md)除外被随机选取的牌来被支付。
   1. 为支付回忆代价，从回忆区随机选取 X 张牌，其中 X 是用于意欲具现的牌的回忆代价。
      1. 非随机形式被支付的代价在随机代价被支付之前被支付。
   2. 在为支付回忆代价而选择牌的时间与那些牌被除外的时间之间，玩家不被给予时机，且不可以采取玩家行动。
4. 若打出牌或启动能力存在任何额外代价，则它们必须在卡牌或效果进入效果堆叠之前，正常代价被支付的相同期间被支付。
5. 若牌或效果将作为该牌结算的结果而指定代价，则这些代价的支付遵循内含的规则文本和时点。

{% hint style="danger" %}
效果和能力可以修改将被支付的代价。
{% endhint %}

6. 为计算被需要的代价，需同时相加由任何进行修改的效果应用的任何代价的增加的数量值，并相减由任何进行修改的效果应用的任何代价的减少的数量值。所得即为需要被支付的代价的数字。
7. 代价的减免和增加通过分别地减少或增加该代价类别来变更牌的默认代价类别。默认代价对于主牌库牌为封存代价，对于素材库牌为回忆代价。
8. 代价不能被减少至 0 以下；若代价将在数字上被减少为 0 以下的数字，则该代价作为代替被设定为 0。
9. 若牌具有由 X 代表的可变代价，则 X 的值被当作其被放置到效果堆叠上之际作为 X 被选择的数字。
   1. 当该牌不位于效果堆叠上期间，X 的值被当作 0，除非当其被认定为明确定义的一组牌（而非隐含的一组）的一部分时。参见下面的示例。
   2. 若具有可变代价的牌被允许不支付其封存代价或回忆代价而被打出，则 X 必须被选择为 0；玩家在此情形不可以为 X 选择任何其他值。
   3. 作为某牌或物件的效果的一部分的值 X 的参照将被当作该牌先前被选择的 X 的值。
   4. 若位于效果堆叠中的具有可变代价的牌被[复制](../../you-xi-ji-zhi/you-xi-ji-zhi-qi-ta/fu-zhi.md)，则被复制的实例将承袭原始牌所选择的 X 的值。

{% hint style="warning" %}
例如，“代价小于 3 的牌”和“代价为 0、1 或 2 的牌”不相同，因为 X 的值认定为 0 ，仅落入隐含的组，不落入明确的组（除非 X 被明确提及）。这对于搜寻或找到代价为 0 的牌同样成立；具体定义为当代价为 0，而非 0 或 X 时，将仅限于选择具有 0 的书面代价的牌。
{% endhint %}

8. 具有 X 代价的物件将被当作具有 0 代价。
   1. 若效果复制战场上的物件，且该物件在其代价中具有任何 X 值或具有先前被设定的 X 值，则该复制将以这些 X 值被设定为 0 的方式被进行。
