# 通用规则 - 卡牌部分

1. 卡牌由名称、代价、类别、职业、属性、速度、力量、生命、耐久和规则文本等部件构成，这些都定义了卡牌的特征。所有卡牌都具有名称、代价、类别、职业和属性。
2. 具有职业奖励能力的卡牌拥有水印图标，这些图标对应于卡牌的职业，以及该职业奖励为哪些英雄职业解锁。这些图标不影响游戏玩法。
