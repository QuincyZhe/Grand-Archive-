# 通用规则 - 牌的组成部分

通用规则：

1. 牌由名称、代价、类别、职业、属性、速度、力量、生命、耐久和规则文本的组件构成，这些均定义牌的特征。所有牌都具有名称、代价、类别、职业和属性。
2. 具有职业奖励能力的牌具有对应于该牌的职业以及该职业奖励被解锁的英雄职业的水印图标。这些图标不影响游戏玩法。
