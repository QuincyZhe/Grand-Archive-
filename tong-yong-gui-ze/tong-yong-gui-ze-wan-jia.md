# 通用规则 - 玩家

在 Grand Archive 的一局游戏的回合期间，玩家被认定为回合玩家和非回合玩家。

通用规则：

1. 回合玩家是操控该回合、回合内阶段的进行、以及回合内主要阶段期间发生的事件的玩家。
2. 当效果堆叠为空时，回合玩家可以在其主要阶段期间的任何时间执行慢速玩家行动。

{% hint style="success" %}
当玩家拥有时机时，可以以快速速度启动能力或打出卡牌。
{% endhint %}

3. 非回合玩家不能在任何时间执行慢速玩家行动。
4. 当回合结束时，回合玩家停止作为回合玩家，且回合顺序中的下一位玩家立即成为回合玩家。
5. 多人游戏被认定为任何包含 3 名或更多玩家的游戏。
