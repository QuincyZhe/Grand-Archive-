# 通用规则 - 玩家

在 Grand Archive 游戏的回合期间，玩家被指认为回合玩家和非回合玩家。

通用规则：

1. 回合玩家是操控该回合、该回合期间阶段的过渡以及该回合内主要阶段期间进行的事件的玩家。
2. 回合玩家可以在其主要阶段期间效果堆叠为空时随时进行慢速玩家行动。

{% hint style="success" %}
玩家可以在具有时机时以快速的速度启动能力或打出牌。
{% endhint %}

3. 非回合玩家不能在任何时候进行慢速玩家行动。
4. 当回合结束时，回合玩家不再为回合玩家，且回合顺序中的下一玩家立即成为回合玩家。
5. 多人对战认定为包括 3 名或更多的玩家的任何游戏。



#### **玩家行动**

1. 玩家行动可以被分隔为玩家在游戏中主动执行的行动与玩家被指示去做的行动。
   1. 玩家在游戏中具有作为选项进行（当被允许时）的行动包括：打出牌和启动能力、使回合阶段前进（包括结束一回合）、宣告攻击，以及传递时机。
   2. 游戏或规则文本也可以指示玩家进行特定行动。这些行动被当作[游戏术语](../yong-yu-ji/you-xi-shu-yu.md)，其中一些也被赋予关键词和/或描述该行动的数量值，例如重复次数或行动的量级。无量级或值的行动示例包括"消灭"、"洗切"、"查看"。这些术语通常将作用于游戏中的某物件，例如消灭物件、洗切牌组，或查看区域中的特定牌。具有量级的玩家行动示例包括"抽"、"预视"和"恢复"。这些行动将连同该行动定义的数字或数量，例如抽 2 张牌、预视 3、或恢复 5。
      1. 对于被分配或涉及数量值的行动，该值必须大于 0 才能发生；例如玩家恢复 0 不认定为进行恢复的行动。具有零重复次数或零量级的行动被当作犹如它们从未生效。
