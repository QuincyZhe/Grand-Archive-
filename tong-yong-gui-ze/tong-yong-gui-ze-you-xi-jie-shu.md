# 通用规则 - 游戏结束

通用规则：

1. Grand Archive 游戏在玩家获胜或游戏以平局结束时结束。



2. 在以下任一情形成立时，玩家赢得游戏：

* 所有对手的英雄死亡
* 所有对手在玩家接收时机时不操控英雄，且这些玩家先前操控英雄
* 该玩家的所有对手都已落败
* 效果写明该玩家在该游戏中已获胜



3. 在以下任一情形成立时，玩家输掉游戏：

* 其英雄死亡
* 该玩家在玩家接收时机时不操控英雄，且先前操控英雄
* 该玩家尝试从空的牌库抽一张牌
* 效果写明该玩家在该游戏中已落败
* 其认输
* 其将同时获胜并输掉



4. 在以下任一为真时，游戏以平局结束：

* 效果写明游戏为平局
* 所有剩余的玩家同时输掉或赢得游戏



5. 当玩家输掉游戏时，该玩家拥有的所有牌和物件被从游戏中移除并移回给该玩家。所有具有指定特性或特征（即超出仅作为牌的特性）的面朝下的牌被展示；这些牌被翻为面朝上并被出示给所有玩家，之后该玩家才可以将这些牌加入其原始牌组以供洗切。（关于特性的信息参见此处【链接】）
   1. 在多人对战中，若该玩家操控其他玩家的物件且该物件没有上一操控者，则该物件将立即在当前比赛中停止存在。否则，该物件将在其上一操控者的操控下移回。
   2. 除了已离开场上的物件，因玩家在游戏中败北而停止存在的物件将不认定为已死亡、被消灭、被除外，或具有应用于其上的任何其他游戏状态变化。

{% hint style="info" %}
例如，若该物件具有"离场时"能力，或将触发另一监测该物件离开场上的物件的能力，则仅这些能力将触发。
{% endhint %}



6. 在游戏之后，所有被拥有的牌和物件之后移回给其各自的拥有者。
7. 若在比赛结构内进行游戏，主牌库和素材库的牌在其各自的牌组中被重新洗切，且衍生被放置一旁。
