# 通用规则 - 游戏结束

通用规则：

1. 当一名玩家获胜或游戏以平局结束时，Grand Archive 游戏结束。<br>
2. 如果以下任何一项成立，则一名玩家获胜：

* 所有对手的英雄死亡
* 当一名玩家获得时机且那些对手此前操控过英雄时，所有对手未操控英雄
* 该玩家的所有对手已落败于游戏
* 一个效果说明该玩家已获胜<br>

3. 如果以下任何一项成立，则一名玩家输掉游戏：

* 他们的英雄死亡
* 当一名玩家获得时机且该玩家此前操控过英雄时，该玩家未操控英雄
* 该玩家尝试从空牌库中抽一张卡牌
* 一个效果说明该玩家已落败
* 他们投降
* 他们将同时获胜和输掉<br>

4. 如果以下任一项成立，则游戏以平局结束：

* 一个效果说明游戏为平局
* 所有剩余玩家同时输掉或获胜<br>

5. 当一名玩家输掉游戏时，该玩家拥有的所有卡牌和物件将从游戏中移除并归还给该玩家。所有具有指定特性或特征（即，除了仅仅是一张卡牌之外的那些）的面朝下卡牌被展示；在将那些卡牌加入他们的初始牌库以供洗切之前，将那些卡牌翻为面朝上并显示给所有玩家。（有关特性的信息，请参阅[此处](../you-xi-ji-zhi/you-xi-ji-zhi-qi-ta/te-xing-yu-zhuang-tai.md)）
   1. 在多人游戏中，如果该玩家操控另一位玩家的物件，且该物件没有此前操控者，则该物件将在当前比赛中立即不再存在。否则，该物件将移回其此前操控者的操控下。
   2. 由于玩家败北而不再存在的物件将不被视为已死亡、被消灭、被放逐，或对其应用任何其他游戏状态的改变，除了该物件已离开战场之外。

{% hint style="info" %}
例如，如果该物件具有“离场时”能力，或将触发另一个监测该物件离开战场的物件的能力，则只有那些能力会触发。&#x20;
{% endhint %}

6. 游戏结束后，所有拥有的卡牌和物件随后被归还给它们各自的拥有者。
7. 如果在比赛结构内进行游戏，主牌库和素材库卡牌将在它们各自的牌库中被重新洗切，且衍生被置于一旁。
