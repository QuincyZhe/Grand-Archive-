# 通用规则 - 游戏开始

**标准对战**

1. 每名玩家将其素材库和主牌库置于相应的区域
2. 每名玩家洗切其主牌库以确保其被充分地随机排列
3. 玩家向其对手提供其主牌库以进行洗切和/或切牌
4. 玩家随机地决定第一回合玩家。这可以通过所有玩家同意的任何随机方法进行。
5. 按回合顺序，玩家进行任何游戏前的行动。
6. 所有玩家将从其各自的素材库展示其起始 Lv 0 英雄并将其放置于战场上。按回合顺序，玩家将结算用于获取其起始手牌的参战时能力。在所有这些能力被结算之前，玩家不能获取时机以进行玩家行动。
7. 第一名玩家进行其第一回合。

例如，类似 The Looking Glass 的牌具有允许玩家以其位于战场上来开始游戏的能力。在步骤 5 期间，他们将被允许将该能力确认为特殊的游戏行动并将此牌放置于战场上。当游戏开始时，将把此牌当作已在第一回合之前于场上。
{% endhint %}

**标准对战 - 第一回合**

1. 每名玩家的第一回合遵循变更的回合顺序：回合玩家略过其唤醒、具现及追忆阶段。
   1. 除非回合玩家是第一回合轮次中的最后一名，否则其不能攻击。例如，在双人对战中，第二名玩家是该第一回合轮次中的最后一名玩家，因此可以宣告攻击。
2. 在双人对战中，第一回合玩家也略过其抽牌阶段。



**万神对战**

1. 每名玩家将其素材库和主牌库置于其相应的区域。玩家也将其低位恩惠和高位恩惠置于其各自的万神区。
2. 每名玩家洗切其主牌库以确保其被充分地随机排列
3. 玩家向其对手之一提供其主牌库以进行洗切和/或切牌
4. 玩家随机地决定第一回合玩家。这可以通过所有玩家同意的任何随机方法进行。在多于两名玩家时，万神玩家回合顺序通过从第一回合玩家起以顺时针方向被定下。
5. 按回合顺序，玩家进行任何游戏前的行动。
6. 所有玩家将从其各自的素材库展示其起始 Lv 0 英雄并将其放置于战场上。此外，每名玩家将一个万神屏障衍生置入场上。按回合顺序，玩家将结算用于获取其起始手牌的参战时能力。在所有这些能力被结算之前，玩家不能获取时机以进行玩家行动。
7. 第一名玩家进行其第一回合，从抽牌阶段开始。

**万神对战 - 第一回合**

1. 每名玩家的第一回合遵循变更的回合顺序：回合玩家略过其唤醒、具现及追忆阶段。与标准对战比赛不同，第一回合玩家在其抽牌阶段期间抽一张牌。
2. 除非回合玩家是第一回合轮次中的最后一名，否则其不能攻击。例如，在四人对战中，第四名玩家是该第一回合轮次中的最后一名玩家，因此可以宣告攻击。
