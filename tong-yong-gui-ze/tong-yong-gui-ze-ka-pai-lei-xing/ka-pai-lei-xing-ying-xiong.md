# 卡牌类别 - 英雄

**通用规则**

1. 英雄也是一种物件类别；一个英雄作为英雄物件被放置在战场上。一个英雄物件也是一个英雄单位。
2. 英雄卡牌开局在素材库中。
3. 一张等级 0 灵魄英雄卡牌必须在每位玩家的第一个回合被放置到战场上。这被视为一个特殊游戏行动且不能被响应。
   1. 玩家不可具现等级 0 英雄。
4. 英雄只能通过攻击卡牌或通过使用武器来攻击。大多数英雄固有地不具有力量数值，因此，不能固有地攻击或针对攻击反击。
   1. 无论是来自攻击卡牌的启动，还是通过武器的攻击宣告，作为攻击的代价会将英雄待命。
   2. 作为攻击卡牌进入意图区的结果而做出的攻击宣告不以待命作为代价。
   3. 具有力量数值的英雄可以不使用攻击卡牌或武器宣告攻击，就如同伙伴那样。
5. 英雄固定地为操控玩家启用非常规属性。传承中的英雄卡牌将赋予玩家对包含在他们属性类别之中的所有属性的使用权。
6. 用于传承的英雄名称一般将被考虑不带前缀、后缀、头衔、称号或任何其他用于卡牌的命名修饰。
7. 英雄可以从素材库被具现，只要他们具有合规的传承要求且是等级 N+1，其中 N 是在该玩家操控下的战场上的英雄的当前等级。
   1. 如果被具现的英雄的等级相对于在场的英雄的等级成为 N+2，该具现变得不合规并失效。
8. 如果一张英雄卡牌将从任何地方被放置进入墓场，改为被放逐。

**升级**

1. 一个英雄可以通过将下一等级英雄卡牌放置在那位英雄的“[传承](../../yong-yu-ji/you-xi-shu-yu.md#lineage-term-chuan-cheng-shu-yu)”顶部来递增地被升级。下一等级英雄被放置在上一等级英雄顶部。这被认知为升级英雄。升级一个英雄可以是具现阶段期间具现一张英雄卡牌的结果，或者指示一位玩家“[升级](../../yong-yu-ji/you-xi-shu-yu.md#level-up-sheng-ji)”他们的英雄的效果的结果。
2. 当一个基本等级为 N+1 的英雄从素材库被选取并被打出（通常通过支付了回忆代价的具现选取）时，英雄由玩家升级。N 指该玩家在战场上的英雄卡牌之一的不考虑额外的等级修改效果的印刷等级。

{% hint style="info" %}
例如，_Lorraine, Wandering Warrior_ 是一个等级 1 英雄，无论有多少效果说明“你的英雄获得 +X 等级”，都可以从素材库升级一个有效的等级 2 英雄进入。&#x20;
{% endhint %}

3. 当具现一个英雄或升级一个英雄时，玩家无视属性要求/制限。

{% hint style="success" %}
例如，一位操控 _Lorraine, Blademaster_ 且在传承中具有 _Spirit of Fire_ 的玩家仍可以将英雄升级 _Lorraine, Crux Knight_ 进入而无需先前启用极星属性。
{% endhint %}

4. 升级一个英雄要求玩家将新英雄卡牌放置在现有英雄卡牌顶部作为传承的一部分。它保持相同的待命/备战特性。即，如果一个待命英雄升级，它将保持待命。
5. 升级一个英雄不使用效果堆叠。如果一张英雄卡牌被具现，升级将作为英雄卡牌结算的结果发生。
6. 由英雄和“[内部传承](../../yong-yu-ji/you-xi-shu-yu.md#inner-lineage-nei-bu-chuan-cheng)”中的卡牌构成的整堆卡牌在其整体中被指为“传承”。
7. 仅传承的顶部卡牌被视为一个物件，即英雄，且“[内部传承](../../yong-yu-ji/you-xi-shu-yu.md#inner-lineage-nei-bu-chuan-cheng)”卡牌内所有继承效果应用于该英雄。
   1. 该英雄被考虑为在战场上的英雄物件。
   2. 一张新英雄卡牌被放置在原始英雄顶部不算作一个新物件进入战场。但是仍将算作一张新英雄卡牌进入传承。因此，那张卡牌对传承的添加将触发传承中最顶端英雄卡牌的任何参战时能力。
      1. 当一个英雄离场或参战时，它将连带其内部传承内的所有卡牌以及其指示物（启迪、等级等）。
      2. 英雄的属性标识由传承内英雄卡牌之中的所有属性构成。
      3. 如果一个新物件将替换当前英雄及其传承，该传承的特质均不延续，例如启迪指示物或伤害指示物。
      4. 仅传承中卡牌之中的继承效果将贡献于传承英雄的效果和能力；无视来自内部传承的任何其他特征，如卡牌名称、代价、职业标识、类别、非继承效果能力、生命数值和力量数值。
8. 玩家只能升级他们操控的英雄。
9. 玩家不能打出也不能升级他们不满足升级要求的英雄。

**降级**

1. 玩家可以降级一个英雄作为代价或作为效果或特定能力的结果。玩家为了降级一个英雄，需要拿取在该英雄传承中的最顶端英雄卡牌并将其移回至素材库。
