# 卡牌类别 - 英雄

**通用规则**

1. 英雄也是一种物件类别；英雄作为英雄物件被放置于战场上。英雄物件也是英雄单位。
2. 英雄牌开局存在于素材库。
3. 等级 0 灵魄英雄牌必须在每名玩家的第一回合被置入场上。此被当作特殊的游戏行动，且不能被响应。
   1. 玩家不可以具现等级 0 英雄。
4. 英雄仅可以通过攻击牌或凭借使用武器进行攻击。大多数英雄本身不具有力量数值，因此本身不能攻击或对攻击进行反击。
   1. 使英雄待命是攻击的代价，无论是从攻击牌的启动，还是由通过武器的攻击宣告。
   2. 因攻击牌进入意图而作出的攻击宣告，不作为代价使英雄待命。
   3. 具有力量数值的英雄可以在无攻击牌或武器的情况下宣告攻击，就像伙伴所能。
5. 英雄固定地为操控其的玩家启用非无属性。传承中的英雄牌将使玩家得以打出其属性类别之中包含的所有属性。
6. 传承的英雄名称一般在被认定时忽略前缀、后缀、头衔、称号或该牌的任何其他命名修饰。
7. 只要英雄具有合规的传承要求且等级为 N+1，其便可以被从素材库具现，其中 N 为由该玩家操控的位于场上的英雄的当前等级。
   1. 若被具现的英雄相对于位于场上的英雄成为 N+2，则该具现成为不合规并失效。
8. 若英雄牌将从任何地方被置入墓场，则其作为代替被除外。

**升级**

1. 英雄可以通过将下一等级的英雄牌放置到该英雄的“[传承](../../yong-yu-ji/you-xi-shu-yu.md#lineage-term-chuan-cheng-shu-yu)”顶部来递增地被升级。之上而被递增地升级。下一等级的英雄被放置到上一等级的英雄之上。此被称作将英雄升级。将英雄升级可以是具现阶段期间具现英雄牌的结果，或是指示玩家“[升级](../../yong-yu-ji/you-xi-shu-yu.md#level-up-sheng-ji)”其英雄的效果的结果。
2. 当基本等级为 N+1 的英雄被从素材库选取并被打出时，玩家升级英雄，该选取通常凭借支付了回忆代价的具现而进行。。N 指该玩家位于场上的英雄牌之一的印刷等级，且不认定额外的等级修正效果。

{% hint style="info" %}
例如，无论有多少效果写明"你的英雄获得 +X 等级"，Lorraine, Wandering Warrior 都是等级 1 英雄，且可以升级为来自素材库的有效的等级 2 英雄。
{% endhint %}

3. 在具现英雄或将英雄升级时，玩家无视属性要求/制限。

{% hint style="success" %}
例如，操控 Lorraine, Blademaster 且其传承中具有 Spirit of Fire 的玩家，仍可以在未先前启用极星属性的情况下将该英雄升级为 Lorraine, Crux Knight。
{% endhint %}

4. 将英雄升级需要玩家将新的英雄牌放置到现有英雄牌之上，作为传承的一部分。其保留相同的待命/备战特性。即，若待命状态的英雄升级，其将仍处于待命状态。
5. 将英雄升级不使用效果堆叠。若英雄牌被具现，则升级将因英雄牌的结算过程而生效。
6. 由英雄与“[内部传承](../../yong-yu-ji/you-xi-shu-yu.md#inner-lineage-nei-bu-chuan-cheng)”中的牌构成的整组牌，其整体被称为"传承"。
7. 仅传承的顶部牌被当作物件，即英雄，且内部传承牌中的所有继承效果应用于英雄。
   1. 英雄被认定为位于战场上的英雄物件。
   2. 被放置到原始英雄之上的新英雄牌不算作进入战场的新物件。其仍将算作进入传承的新英雄牌。因此，将该牌加入传承将触发传承中最顶端的英雄牌的任何参战时能力。
      1. 当英雄离场或进入战场时，其将连同其内部传承中的所有牌以及其指示物（启迪、等级等）离场或进入战场。
      2. 英雄的属性标识由传承之内的英雄牌之中包含的所有属性构成。
      3. 若新物件将替代当前英雄及其传承，则该传承的任何特质（例如启迪指示物或伤害指示物）均不延续。
      4. 仅传承中的牌之中的继承效果将对传承的英雄的效果和能力起作用；内部传承中的任何其他特征，例如牌名、代价、职业标识、类别、非继承效果能力、生命数值和力量数值，被无视。
8. 玩家只能升级其操控的英雄。
9. 玩玩家不能打出或升级不符合等级要求的英雄。

**降级**

1. 作为代价，或作为效果或特定能力的结果，玩家可以将英雄降级。为使英雄降级，该玩家取出该英雄传承中最顶端的英雄牌并将其移回素材库。
