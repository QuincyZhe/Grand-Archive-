# 卡牌类型 - 伙伴

通用规则：

1. 伙伴也是一种物件类别；在一个伙伴结算后，它将作为一个伙伴物件进入战场。一个伙伴物件也是一个伙伴单位。
   1. 它们可以攻击（如果备战），可以被攻击，可以反击（如果备战），且可以作为“目标单位”或“目标伙伴”成为效果的目标或选择。
2. 伙伴在主牌库中具有封存代价。如果它们在素材库中，伙伴卡牌具有礼装超类别并将代替封存代价具有回忆代价。
3. 伙伴卡牌只能以慢速速度被打出。
4. 伙伴物件进入战场时为备战。
5. 当伙伴物件备战时可以攻击。
6. 当伙伴物件被消灭时，一张伙伴卡牌进入其拥有者的墓场。
   1. 具有 0 生命或小于 0 生命，或者被标记的伤害量等于或大于其生命数值的伙伴，将在任何玩家可以执行任何玩家行动之前，作为基于状态的效果的结果自动被消灭。
